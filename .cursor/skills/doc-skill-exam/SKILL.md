## 一、实用技巧（表格 / 文档工具）

### 1.1 一键快速汇总求和

**问题**

> 如何一键快速汇总求和？

**答案要点**

- 选中数据区域后，使用 **AutoSum（自动求和）** 功能
- 常用快捷键：**Alt + =**（Excel/WPS 通用）
- 一键在行/列末尾生成 **SUM** 求和结果

**易考点**

| 项 | 说明 |
|----|------|
| 功能名 | **自动求和 / AutoSum** |
| 快捷键 | **Alt + =** |
| 适用 | 行汇总、列汇总、区域汇总 |

1. **默写**：某一整块（如文档结构 / 写作规范）
2. **对比**：常见文档类型差异（如需求文档 vs 设计文档 vs 用户手册）
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点
