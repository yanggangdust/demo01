## 复习互动方式

1. **默写**：某一整块（如文档结构 / 写作规范）
2. **对比**：常见文档类型差异（如需求文档 vs 设计文档 vs 用户手册）
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点

回答时：先结论再展开；中文作答；紧扣本 skill，不擅自扩展成无关百科。考试时用户要求「只给答案」则只列要点。
