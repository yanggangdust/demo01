### 1.1 云计算行业监管政策要求安全管控

**顶部概述（课件）**

- 底部结论：**产业数字化 + 内循环 + 网络安全** → 运营商/国家队机遇
- 易错点：**三新一高**≠双循环；7 大产业勿漏**工业互联网/区块链/VR·AR**；混合云是十四五**重点**，非仅公有云

### 1.2 中国移动助力国家数字经济发展

**顶部概述（课件）**

中国移动发布 **"5G+AICDE"** 计划，以 **5G** 发展为契机，与**云计算、物联网、人工智能**等信息技术深度融合，打造**泛在智能基础设施**。**移动云**是 **5G+ 计划**重要组成部分。

**5G+AICDE 构成（泛在智能基础设施）**

| 字母 | 英文 | 中文 |
|------|------|------|
| **5G** | 5G | 第五代移动通信 |
| **A** | AI | **人工智能** |
| **I** | IoT | **物联网** |
| **C** | Cloud | **云计算** |
| **D** | Big Data | **大数据** |
| **E** | Edge Cloud | **边缘云** |

**速记口诀**

> 5G + **A**I **I**oT **C**loud **D**ata **E**dge

**三大战略支柱（三融）**

| 支柱 | 名称 | 含义 |
|------|------|------|
| **融合** | 云智/云网/云边/云数 | **云智、云网、云边、云数**融合，强化协同效应 |
| **融通** | 开放生态 | 构建**开放生态系统**，实现**能力和要素**整合 |
| **融智** | 智能运维 | **集中化、智能化**打造高效**运营运维**体系 |

**四融详解（融合）**

| 融合类型 | 含义 |
|---------|------|
| **云智融合** | 云 + 人工智能 |
| **云网融合** | 云 + 网络（5G 等） |
| **云边融合** | 云 + 边缘计算 |
| **云数融合** | 云 + 大数据 |

**十大行业应用（课件图标行）**

| # | 行业 |
|---|------|
| 1 | **政务** |
| 2 | **教育** |
| 3 | **医疗** |
| 4 | **制造** |
| 5 | **金融** |
| 6 | **交通** |
| 7 | **电商** |
| 8 | **能源** |
| 9 | **文娱** |
| 10 | **IT** |

**易考点**

- 中国移动战略 = **5G+AICDE** 计划
- 基础设施目标 = **泛在智能基础设施**
- **移动云** = 5G+ 计划**重要组成部分**（非附属产品）
- AICDE 五要素 = **AI / IoT / Cloud / Big Data / Edge Cloud**
- 三融 = **融合 + 融通 + 融智**
- 四融（融合内）= **云智 + 云网 + 云边 + 云数**
- 融通侧重**开放生态**；融智侧重**集中化、智能化 O&M**
- 十大行业：政务/教育/医疗/制造/金融/交通/电商/能源/文娱/IT
- 易错点：**E = Edge Cloud（边缘云）**，非其他；移动云是**5G+核心组成**，非独立业务线

### 1.4 移动云发展历程

**顶部概述（课件）**

自第一行代码诞生以来，移动云已走过**十余年**历程。从诞生之初就怀揣**"建云为国"**的志向，紧跟产业政策，积极创新，已成长为推动中国云计算产业发展的重要力量。

**五阶段发展曲线**

| 阶段 | 时期 | 阶段标签 | 关键词 |
|------|------|---------|--------|
| 1 | **2007~2013** | 起步探索 | 初始建设、探索阶段 |
| 2 | **2014~2019** | **提质**，内外部**规模化商用** | 苏州研发中心、规模化 |
| 3 | **2019** | **云改** | 云能力中心、管战建协同 |
| 4 | **2020~2022** | **腾飞**，关键核心**技术可控** | 国内**第一阵营** |
| 5 | **2023~** | **赋能**，云向**算力网络**演进 | 世界一流云服务商 |

**关键里程碑**

| 时间 | 事件 | 要点 |
|------|------|------|
| **2014 年** | 注资成立**苏州研发中心** | 中国移动注资 **31.72 亿元**；打造 IT 能力内化和业务创新的**中坚力量** |
| **2019 年** | **"云改"**拉开序幕 | 在苏州研发中心基础上挂牌成立**中国移动云能力中心**；**管战建**协同发力 |
| **2022 年** | 进入**第一阵营** | 移动云进入国内云服务商**第一阵营** |
| **2023 年 3 月** | 国资委首批示范企业 | **云能**入选国资委首批**"创建世界一流专精特新示范企业"** |

**2023+ 新征程（课件红色标题）**

> 开启**"成为一流云服务商"**新征程

**第五阶段方向**

| 维度 | 内容 |
|------|------|
| 演进方向 | 云向**算力网络**演进 |
| 服务目标 | 深度服务社会**数智转型** |
| 战略愿景 | **成为一流云服务商** |

**阶段速记口诀**

> 起步（07-13）→ 提质商用（14-19）→ 云改（19）→ 腾飞第一阵营（20-22）→ 赋能算力网络（23+）

**与 1.3 呼应**

| 1.3 节点 | 1.4 展开 |
|---------|---------|
| 2019.7 云能力中心 | 2019 云改 + 管战建协同 |
| 2019.11 三年规划 | 2014~2019 提质规模化商用阶段 |

**易考点**

- 移动云历程 **10 余年**；初心 = **"建云为国"**
- 五阶段标签：**起步 → 提质 → 云改 → 腾飞 → 赋能**
- **2014**：注资 **31.72 亿** → **苏州研发中心**
- **2019**：**云改** + **云能力中心**（苏州基础上）+ **管战建**协同
- **2022**：国内云服务商**第一阵营**
- **2023.3**：云能 → 国资委首批**"创建世界一流专精特新示范企业"**
- 2023+ 方向：云 → **算力网络**；愿景 = **一流云服务商**
- 易错点：**31.72 亿**是 2014 苏州研发中心（非 2019）；**第一阵营**是 2022（非 2023）；**云能**=云能力中心简称

### 1.5 移动云顶层设计

**顶部概述（课件）**

围绕移动云，中国移动构建了**"管战建"一体化协同**的组织体系，通过整合**总部、省公司、产研院和专业公司**的分类资源，实现**渠道、网络、客户、技术**等在云领域的**力出一孔**；在"管战建"模式牵引下，集团内优势资源向移动云**快速聚焦**，加速移动云成为**一流云服务商**。

**组织架构（管战建 + 研）**

```
              集团总部（管）
         资源统筹调度 / 政策管理支撑
                    │
         ┌──────────┼──────────┐
         │   管战建协同          │
    省公司（战）  云能力中心（建）  产研院/专业公司（研）
         └──────────┼──────────┘
                    │
              资源聚焦 → 移动云
```

**四大主体及职责**

| 主体 | 角色 | 简称 | 职责 |
|------|------|------|------|
| **集团总部** | 管 | 管 | **资源统筹调度**、**政策管理支撑** |
| **省公司** | 战 | 战 | 一线**作战**/销售落地 |
| **云能力中心** | 建 | 建 | **建设**移动云核心能力（图中绿色节点） |
| **产研院 / 专业公司** | 研 | 研 | **研发**与专业技术支撑 |

**协同关系（连线标注）**

| 协同路径 | 关系类型 | 具体内容 |
|---------|---------|---------|
| 省公司 ↔ 云能力中心 | **战建协同** | **销售支撑**、**资源支撑** |
| 云能力中心 ↔ 产研院/专业公司 | **建研协同** | **技术支撑**、**产品支撑** |
| 四者交汇 | **管战建协同** | 总部统筹下的整体协同 |

**核心机制**

| 机制 | 含义 |
|------|------|
| **力出一孔** | 渠道、网络、客户、技术等资源**统一聚焦**云领域 |
| **资源聚焦** | 集团优势资源向**移动云**集中（图示大箭头） |
| **管战建一体化** | 管理（总部）+ 作战（省公司）+ 建设（云能力中心）协同 |

**易考点**

- 顶层设计核心 = **"管战建"一体化协同**组织体系
- 四大主体：**总部（管）+ 省公司（战）+ 云能力中心（建）+ 产研院/专业公司（研）**
- **管**职责：资源统筹调度 + 政策管理支撑
- **战建协同**：销售支撑 + 资源支撑（省公司 ↔ 云能力中心）
- **建研协同**：技术支撑 + 产品支撑（云能力中心 ↔ 产研院/专业公司）
- 核心目标：**力出一孔** → **资源聚焦** → 移动云
- 与 1.4 呼应：2019 **管战建**协同发力
- 易错点：**云能力中心**是"建"（非"管"）；**省公司**是"战"（非"建"）；还有**研**（产研院/专业公司），共四主体
