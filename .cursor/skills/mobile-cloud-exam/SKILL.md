## 复习互动方式

1. **默写**：某一整块（如产品体系 / 架构层次 / 核心能力）
2. **对比**：常见概念差异（如 IaaS vs PaaS vs SaaS、公有云 vs 私有云）
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点

回答时：先结论再展开；中文作答；紧扣本 skill，不擅自扩展成无关百科。考试时用户要求「只给答案」则只列要点。
