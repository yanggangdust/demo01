### 1.1 云计算行业监管政策要求安全管控

**顶部概述（课件）**

国家推进数字经济发展战略下，出台政策力度不减，企业数字化转型进度加快，**上云进入深化应用阶段**；同时，国家对法律法规、准入门槛、行业标准提出更高要求，对互联网垄断、数据滥用加强监管力度，部分互联网云服务商发展出现不确定风险，**央企竞争力相应提升**。

**政策时间线（2020.10 — 2021.10）**

| 时间 | 事件/政策 | 核心要点 |
|------|----------|---------|
| **2020.10.26** | **十九届五中全会** | **三新一高**成为发展基本方针，着力提高发展质量和效益 |
| **2020.12.16** | **中央经济工作会议** | 加快构建**以国内大循环为主体、国内国际双循环**相互促进的新发展格局 |
| **2021.3.12** | **"十四五"规划 & 2035 远景目标纲要** | **数字中国**建设提到新高度，重点关注**混合云**解决方案 |
| **2021.4.30** | **中共中央政治局会议** | 深化供给侧改革，为"十四五"经济发展提供持续动力 |
| **2021.7.10** | **网络安全、数据安全**需求提升 | **"自主可控"与"安全"**成为央企、大型企业等**国家队**新机遇 |
| **2021.10.18** | **中央政治局第三十四次集体学习** | 推动我国**数字经济健康发展** |

**底部总结（课件）**

> **三新一高**为发展基本方针，国家战略驱动行业加快发展；除社会经济**产业数字化**、**畅通内循环**趋势外，**网络安全**为运营商等**国家队**带来新机遇新导向。

**易考点**

- 上云阶段：进入**深化应用阶段**
- 发展基本方针 = **三新一高**（十九届五中全会，2020.10.26）
- 双循环 = **国内大循环为主体 + 国内国际双循环**（2020.12.16）
- 十四五数字重点 = **数字中国** + **混合云**；7 大产业：**云大物工链人 V**
- 云计算技术方向：**云操作系统、分布式存储、弹性计算、数据虚拟隔离、云安全**
- 2021.7 关键词：**自主可控、安全、国家队、网络安全下半场**
- 2021.10.18：数字经济**健康发展**；**发展与安全**统筹
- 底部结论：**产业数字化 + 内循环 + 网络安全** → 运营商/国家队机遇
- 易错点：**三新一高**≠双循环；7 大产业勿漏**工业互联网/区块链/VR·AR**；混合云是十四五**重点**，非仅公有云
