## 复习互动方式

1. **默写**：某一整块（如 inode 结构 / 挂载流程 / 软硬链接对比）
2. **对比**：软链接 vs 硬链接；ext4 vs xfs；文件 vs 目录
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点

回答时：先结论再展开；中文作答；紧扣本 skill，不擅自扩展成无关百科。考试时用户要求「只给答案」则只列要点。
