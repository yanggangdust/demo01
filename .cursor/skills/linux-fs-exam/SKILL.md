# Linux 文件系统 考试考点（周四复习）

按网课目录三章组织。用户刷课时发截图，逐步填充各章考点。

## 一、Linux 磁盘管理与分区
> 待补充：磁盘设备命名、MBR/GPT、分区工具（fdisk/parted）、分区类型、查看磁盘等。

## 二、Linux 常用文件系统
> 待补充：ext4/XFS/Btrfs 等文件系统、格式化、挂载/卸载、fstab、inode、软硬链接等。

## 三、Linux 逻辑卷管理（LVM）
> 待补充：PV/VG/LV 概念、创建与扩展、快照、扩容缩容流程等。

## 复习互动方式

1. **默写**：某一整块（如 LVM 三层 / 挂载流程 / 软硬链接对比）
2. **对比**：软链接 vs 硬链接；ext4 vs xfs；MBR vs GPT；PV/VG/LV
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点

回答时：先结论再展开；中文作答；紧扣本 skill，不擅自扩展成无关百科。考试时用户要求「只给答案」则只列要点。
