## 一、Linux 磁盘管理与分区

### 1.1 原理知识

#### 硬盘与分区

| 问题 | 要点 |
|------|------|
| **什么是硬盘** | 计算机中存放信息的**主要存储设备**就是硬盘 |
| **为什么要分区** | 硬盘**不能直接使用**，必须对硬盘进行**分割**；分割成的一块一块的硬盘区域就是**分区** |

易考点：硬盘不能直接用 → 必须分区；分区 = 对硬盘分割后的一块区域。

#### 主分区与扩展分区

传统磁盘管理中，硬盘分为两大类分区：**主分区** 和 **扩展分区**。

| 类型 | 要点 |
|------|------|
| **主分区（Primary）** | 可安装操作系统、可从此启动；可直接格式化、装系统、存文件 |
| **扩展分区（Extended）** | **不能直接使用**，必须再分割（二次分区）才能用 |
| **逻辑分区（Logical）** | 在扩展分区内再分出来的分区 |

易考点：主分区可直接用（装系统/存文件）；扩展分区不能直接用，必须再分成逻辑分区才可用。

#### MBR 分区限制（常考点）

| 规则 | 要点 |
|------|------|
| 主分区上限 | MBR 分区表类型下，一块硬盘最多 **4 个主分区** |
| 需要更多分区时 | 必须用**扩展分区**；此时最多 **3 个主分区 + 1 个扩展分区** |
| 扩展分区数量 | 一块盘扩展分区要么 **0 个**，要么最多 **1 个** |
| 逻辑分区 | 扩展分区不能直接存数据，必须再分成逻辑分区才可用；扩展分区内逻辑分区数量**无固定上限**（任意多个） |

易考点：MBR 最多 4 主；有扩展时 = 最多 3 主 + 1 扩展；扩展只能 0 或 1 个；逻辑分区数量不限。

#### MBR（主引导记录）定义与结构

**定义**：主引导记录（MBR, Master Boot Record）是采用 MBR 分区表的硬盘的**第一个扇区**，即 C/H/S 地址的 **0 柱面 0 磁头 1 扇区**，也叫 MBR 扇区。

**组成（共 512 字节）**：

| 部分 | 大小 | 作用 |
|------|------|------|
| **主引导程序（boot loader）** | **446 字节** | 引导程序 |
| **硬盘分区表 DPT（Disk Partition Table）** | **64 字节** | 记录分区数量及每个分区大小 |
| **分区有效标志** | **2 字节** | 有效标志（magic number） |

易考点：MBR = 第一个扇区（0柱面0磁头1扇区），共 512 字节 = 446（boot loader）+ 64（DPT）+ 2（有效标志）。DPT 记分区个数与大小。

### 1.2 磁盘管理

#### 管理规则

1. **设备访问路径**：Linux 通过设备名访问设备，设备名存放在 **`/dev`** 目录。
2. **不同接口命名**：
   | 接口类型 | 前缀 | 示例 |
   |----------|------|------|
   | SCSI 类（SSD / SAS / SATA） | **`sd`** | `/dev/sda` |
   | IDE | **`hd`** | `/dev/hda` |
3. **分区命名规则**：设备名 + 分区号
   - **1–4**：保留给**主分区**或**扩展分区**
   - **5 及以上**：表示**逻辑分区**
   - 例：`/dev/sda5` = 第一块 SCSI/SATA 盘上的第一个逻辑分区

易考点：设备在 `/dev`；SATA/SSD/SAS→`sd`，IDE→`hd`；分区号 1–4=主/扩展，≥5=逻辑。

#### 规则示例

| 说明 | 名称 |
|------|------|
| IDE1 接口第1个硬盘（master）的第1个分区 | `/dev/hda1` |
| IDE1 接口第2个硬盘（slave）的第1个分区 | `/dev/hdb1` |
| IDE2 接口第1个硬盘（master）的第3个分区 | `/dev/hdc3` |
| IDE2 接口第2个硬盘（slave）的第1个逻辑分区 | `/dev/hdd5` |
| SCSI 接口第1个硬盘（ID=0）的第1个分区 | `/dev/sda1` |
| SCSI 接口第2个硬盘（ID=1）的第2个逻辑分区 | `/dev/sdb6` |

记忆：IDE 按 a/b/c/d 对应 IDE1 master/slave、IDE2 master/slave；SCSI/SATA 按 a/b…；逻辑分区从 **5** 起（如 hdd5、sdb6）。

### 1.3 分区工具

#### 分区工具 fdisk

- **定义**：Linux 原生工具，用于观察磁盘使用情况、对硬盘分区。
- **语法**：`# fdisk [ -l ] [设备名]`

| 命令 | 作用 |
|------|------|
| `fdisk -l` | 查看系统**所有分区**情况 |
| `fdisk -l /dev/sda` | 查看设备 `/dev/sda` 的分区情况 |
| `fdisk /dev/sda` | **交互式**对 `/dev/sda` 进行分区管理 |

易考点：`fdisk -l` 看全部；指定设备看该盘；不加 `-l` 进入交互式分区。

#### fdisk 常用参数（交互式）

| 键 | 作用 |
|----|------|
| `m` | 显示各参数说明（帮助） |
| `p` | 显示硬盘分区表 |
| `d` | 删除已有分区 |
| `n` | 增加新分区 |

**新建分区流程**：
1. 输入 `n` → 选择主分区 `p` 或扩展分区 `e`
2. 输入分区号（主分区 1–4）
3. 设置起止柱面 / 大小（如 `+sizeM`）

**分区类型与保存**：
- 新建分区默认类型为 **Linux Native**。
- `t`：修改分区系统 ID/类型；`l`：列出所有支持的分区类型及代码。
- `w`：**写入磁盘并退出**（保存）；`q`：**不保存直接退出**。

易考点：交互式常用 `m/p/d/n`；新建时选 `p`（主）或 `e`（扩展），再定分区号与大小；默认 Linux Native；改类型用 `t`/`l`；保存用 `w`，放弃用 `q`。

## 二、Linux 常用文件系统

### 2.1 认识文件系统

#### 文件系统概念

文件系统是一种**存储和组织计算机数据**的方法，使访问和查找变得容易。

**核心要点**：
- 使用**文件**和**树形目录**的抽象逻辑概念。
- 用户保存数据时**不必关心**数据实际存在硬盘哪个地址的数据块上。
- 只需记住该文件的**所属目录**和**文件名**。

**Linux 根目录树（示意）**：
- 根：`/`
- 一级目录：`/bin` `/boot` `/dev` `/etc` `/home` `/lib` `/media` `/mnt` `/opt` `/root` `/sbin` `/srv` `/tmp` `/usr` `/var`
- 例：`/usr` → `/bin` `/include` `/lib` `/sbin`；`/var` → `/cache` `/log` `/spool` `/tmp`

易考点：文件系统 = 文件 + 树形目录抽象；用户只记目录和文件名，不关心物理块地址。
