## 一、建立演讲自信心

> 本章目录（Part 1）：演讲最大的敌人 → 建立自信：PBM 九步法。

### 1.1 演讲最大的敌人

**核心结论（课件标题）**

> **演讲最大的敌人：恐惧和怯场**

| 敌人 | 含义 |
|------|------|
| **恐惧** | 对演讲/公开表达的心理害怕 |
| **怯场** | 面对听众时的紧张、放不开 |

**恐惧和怯场的表现**（课件列举，共 5 组）

| 序号 | 表现 |
|:----:|------|
| 1 | **手足无措**；**面红耳赤** |
| 2 | **呼吸急促**；**喉咙发紧** |
| 3 | **手心出汗**；**双腿发抖** |
| 4 | **表情僵硬**；**头脑空白** |
| 5 | **说话结巴**；**卡壳忘词** |

**引出的核心问题（课件气泡）**

> **如何建立自信心？**

→ 对应本章 **1.2 建立自信：PBM 九步法**

**易考点**

- 演讲最大敌人 = **恐惧 + 怯场**（两个，非单一）
- 恐惧与怯场：**恐惧**偏心理层面；**怯场**偏现场表现层面
- **表现共 5 组、10 项**，每组两个并列症状，默写时成对记忆
- 身体反应类：呼吸急促/喉咙发紧、手心出汗/双腿发抖、面红耳赤
- 表达障碍类：说话结巴/卡壳忘词、头脑空白、表情僵硬、手足无措
- 解决方向 → **如何建立自信心？**（1.2 PBM 九步法）
- 易错点：最大敌人不是"内容不熟"或"听众挑剔"，而是**恐惧和怯场**

### 1.2 建立自信：PBM 九步法

**PBM 九步法**（Practice · Brain · 身体七部位，共 9 步）

| 步 | 英文/部位 | 要点 |
|:--:|-----------|------|
| 1 | **Practice** | 克服恐惧最好方法：除了练习，还是练习 |
| 2 | **Brain** | 积极肯定的自我暗示 |
| 3 | **Face** | 表情放松而和谐 |
| 4 | **Eye** | 不要急于开口，先环视听众几秒钟，寻找一个亲切的面孔 |
| 5 | **Nose** | 深吸气 |
| 6 | **Mouth** | 大声开口，解除紧张，激活脑能量 |
| 7 | **Hand** | 双手用力推墙或推桌子 |
| 8 | **Foot** | 迅速阔步，比平时快 **15%** |
| 9 | **Body** | 昂首挺胸，伸直腰杆 |

#### 1.2.1 第一步：Practice（练习）

**核心结论（课件标题）**

> **Practice：克服恐惧最好方法，除了练习，还是练习**

**三种练习方式**（课件三要素图）

| 练习方式 | 作用/目的 |
|----------|-----------|
| **情景练习** | **自我发现问题** |
| **个人练习** | **加强内容记忆** |
| **实际练习** | **多种表现方式** |

**易考点**

- PBM 第一步 = **Practice（练习）**
- 克服恐惧最好方法：**除了练习，还是练习**（反复练习）
- 三种练习方式与作用一一对应，默写勿混：
  - **情景练习** → 自我发现问题（非"加强记忆"）
  - **个人练习** → 加强内容记忆（非"发现问题"）
  - **实际练习** → 多种表现方式（非"自我发现"）
- 易错点：三种练习按**目的**区分，不是按场合大小简单排列

#### 1.2.2 第二步：Brain（积极肯定的自我暗示）

**核心结论（课件标题）**

> **Brain —— 积极肯定的自我暗示**

**课件示例（两种自我暗示句式）**

| 对象 | 自我暗示语 |
|------|------------|
| **对自己** | **我很高兴来到这里！** |
| **对听众** | **我很高兴你们来到这里！** |

**易考点**

- PBM 第二步 = **Brain（大脑/心理）**，核心是**积极肯定的自我暗示**
- 两种句式区分对象：
  - **我很高兴来到这里** → 对自己（缓解自身紧张）
  - **我很高兴你们来到这里** → 对听众（建立连接、正向开场心态）
- 易错点：第二步不是"更多练习"，而是**心理层面的积极暗示**；与第一步 Practice 形成「练 + 想」配合

#### 1.2.3 第三至九步：身体部位法（Face ~ Body）

**核心结论（课件标题）**

> **建立自信：PBM 九步法之三至九**

第三至九步按 **Face → Eye → Nose → Mouth → Hand → Foot → Body** 七个身体部位，对应上表第 3~9 步。

**易考点**

- PBM 全称逻辑：**P**ractice + **B**rain + 身体 **7** 部位 = **9 步**
- 第三至九步顺序（默写从上到下）：**Face → Eye → Nose → Mouth → Hand → Foot → Body**
- 各步动作勿混：
  - **Eye** → 先环视、找亲切面孔（非"深吸气"）
  - **Nose** → **深吸气**（非"大声开口"）
  - **Mouth** → **大声开口**，解除紧张、激活脑能量
  - **Hand** → 推墙/推桌子（释放肢体紧张）
  - **Foot** → 阔步比平时快 **15%**（数字考点）
  - **Body** → 昂首挺胸、伸直腰杆
- 易错点：**Nose 吸气、Mouth 开口** 分属两步；Foot 的 **15%** 是课件明确数据

## 二、演讲的三要素

> 本章目录（Part 2）：Verbal · Vocal · Visual 三要素。

**核心结论（课件 Part 2 标题页）**

> **演讲的三要素**

| 英文 | 中文含义 | 指什么 |
|------|----------|--------|
| **Verbal** | 你所说的**内容** | 讲什么（文字/信息/论点） |
| **Vocal** | 你所说的**方式** | 怎么说（语调、语速、音量、节奏等） |
| **Visual** | **形体语言** | 怎么看（姿态、表情、手势、眼神等） |

**易考点**

- 三要素英文首字母：**V · V · V**（Verbal / Vocal / Visual）
- 三者分工（默写核心）：
  - **Verbal** = **内容**（what）
  - **Vocal** = **方式**（how you say）
  - **Visual** = **形体语言**（how you look）
- 易错点：
  - Vocal ≠ 内容，Visual ≠ 说话方式
  - **Visual** 是形体语言，不是 PPT/视觉辅助材料（课件未在此展开）
- 对比记忆：内容 · 声音 · 形体，缺一不可

## 复习互动方式

1. **默写**：某一整块（如演讲三要素 / 开场结尾技巧 / 自信心建立）
2. **对比**：常见方法差异（如 口头表达 vs 书面表达、开场 vs 结尾技巧）
