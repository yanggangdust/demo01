### 1.1 管理者角色与解决问题

**核心观点（左侧竖排）**

> 一位管理者的主要角色是**通过别人来完成工作**！

**管理者角色流程图（课件）**

```
管理者 ──→ 解决问题的能力 ──┬→ 人员管理 ──┐
                            └→ 事务成果 ←─┘
```

| 要素 | 含义 |
|------|------|
| **管理者** | 管理工作的主体 |
| **解决问题的能力** | 管理者的核心能力（中间枢纽） |
| **人员管理** | 管理输出之一：管人 |
| **事务成果** | 管理输出之二：管事/出成果 |

**流程关系**

- 管理者靠**解决问题的能力**，实现**人员管理**和**事务成果**
- **人员管理 → 事务成果**：管人是为了出成果（右侧弧形箭头）

**底部总结（红色横幅）**

> 优秀的管理者，就是**永远在条件不充分具备的情况下**，带领团队**出色完成任务**的人

**易考点**

- 管理者主要角色 = **通过别人来完成工作**（非自己亲力亲为）
- 管理者核心能力 = **解决问题的能力**（连接角色与两大输出）
- 两大管理输出 = **人员管理 + 事务成果**
- 关系链：管理者 → 解决问题能力 → 人员管理 → 事务成果
- 优秀管理者定义：**条件不充分**时仍能**带领团队出色完成任务**
- 易错点：管理者≠自己做事，而是**通过别人**；解决问题能力是**枢纽**，不是可有可无

## 复习互动方式

1. **默写**：某一整块（如五步法流程 / 分析工具 / 方案确认步骤）
2. **对比**：常见方法差异（如 5why vs 鱼骨图、界定问题 vs 要因分析）
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点

回答时：先结论再展开；中文作答；紧扣本 skill，不擅自扩展成无关百科。考试时用户要求「只给答案」则只列要点。
