## 一、什么是问题分析与解决

> 本章目录（Part 1）：管理者角色与解决问题 → 问题分析与解决的步骤 → 问题分析与解决的价值 → 课程目标。

### 1.1 管理者角色与解决问题

**核心观点（左侧竖排）**

> 一位管理者的主要角色是**通过别人来完成工作**！

**管理者角色流程图（课件）**

```
管理者 ──→ 解决问题的能力 ──┬→ 人员管理 ──┐
                            └→ 事务成果 ←─┘
```

| 要素 | 含义 |
|------|------|
| **管理者** | 管理工作的主体 |
| **解决问题的能力** | 管理者的核心能力（中间枢纽） |
| **人员管理** | 管理输出之一：管人 |
| **事务成果** | 管理输出之二：管事/出成果 |

**流程关系**

- 管理者靠**解决问题的能力**，实现**人员管理**和**事务成果**
- **人员管理 → 事务成果**：管人是为了出成果（右侧弧形箭头）

**底部总结（红色横幅）**

> 优秀的管理者，就是**永远在条件不充分具备的情况下**，带领团队**出色完成任务**的人

**易考点**

- 管理者主要角色 = **通过别人来完成工作**（非自己亲力亲为）
- 管理者核心能力 = **解决问题的能力**（连接角色与两大输出）
- 两大管理输出 = **人员管理 + 事务成果**
- 关系链：管理者 → 解决问题能力 → 人员管理 → 事务成果
- 优秀管理者定义：**条件不充分**时仍能**带领团队出色完成任务**
- 易错点：管理者≠自己做事，而是**通过别人**；解决问题能力是**枢纽**，不是可有可无

### 1.2 问题分析与解决的步骤

**四步循环流程（课件，顺时针，中心：系统思维）**

```
            1 界定问题
               ↑
4 落地执行 ← [系统思维] → 2 要因分析
               ↓
            3 确认方案
```

**中心核心**

| 要素 | 含义 |
|------|------|
| **系统思维** | 问题分析与解决的基础思维（贯穿四步） |

**四步清单**

| 步骤 | 名称 | 位置 | 图标含义 |
|------|------|------|---------|
| 1 | **界定问题** | 上 | 框定/定义问题范围 |
| 2 | **要因分析** | 右 | 分析关键要因/根因 |
| 3 | **确认方案** | 下 | 确定解决方案 |
| 4 | **落地执行** | 左 | 执行落地 |

**与课程五章对应**

| 步骤 | 对应章节 |
|------|---------|
| 1 界定问题 | 第二章 |
| 2 要因分析 | 第三章 |
| 3 确认方案 | 第四章 |
| 4 落地执行 | 第五章 |

**速记口诀**

> 界定 → 要因 → 确认 → 落地（以**系统思维**为核心）

**易考点**

- 问题分析与解决四步 = **界定问题 → 要因分析 → 确认方案 → 落地执行**（顺时针）
- 中心核心 = **系统思维**（非某一步，而是贯穿全程的基础思维）
- 四步与课程第二~五章**一一对应**
- 流程特点：**循环/迭代**（四步首尾相连，非一次性线性）
- 易错点：第一步是**界定问题**（非直接分析原因）；核心是**系统思维**（非"分析问题"本身）

### 1.3 问题分析与解决的价值

**中心核心：系统思维**

四价值围绕**系统思维**展开：

```
        有始有终              组织效率
           ╲                ╱
            ╲  系统思维  ╱
             ╲          ╱
        由繁到简        整体致胜
```

**四大价值**

| # | 价值 | 关键词 | 详解 |
|---|------|--------|------|
| 1 | **有始有终** | 四步法整体推进 | 用四步法**从头到尾**推进，不半途而废 |
| 2 | **由繁到简** | 初学繁琐→熟练省时 | **初学**觉得步骤繁琐；**熟练后**节约时间 |
| 3 | **组织效率** | 统一行动、降沟通成本 | 组织**统一行动**，**减少沟通成本**，**提升整体效率** |
| 4 | **整体致胜** | 局部→全面→系统致胜 | 由**局部/某个点**取胜，进而**全面致胜、系统致胜** |

**速记口诀**

> 有始有终、由繁到简、组织效率、整体致胜

**易考点**

- 问题分析与解决四大价值 = **有始有终 + 由繁到简 + 组织效率 + 整体致胜**
- 均以**系统思维**为中心
- **有始有终**：四步法**整体推进**（非跳步）
- **由繁到简**：**初学繁琐 vs 熟练省时**（对比考点）
- **组织效率**：**统一行动 + 减少沟通成本 + 提升效率**
- **整体致胜**：**局部点取胜 → 全面致胜 → 系统致胜**（递进关系）
- 与 1.2 呼应：有始有终对应**四步法**；整体致胜对应**系统思维**
- 易错点："由繁到简"不是步骤变少，而是**熟练后效率提升**；整体致胜强调**系统**而非单点

## 二、界定问题

> 本章目录（Part 2）：界定问题四步法 → 发现异常现象维度 → 优选矩阵 → 优选矩阵注意事项 → 是问题吗 → 什么是问题 → 白色思考帽 → 描述期望值工具 → 问题描述案例。

### 2.1 界定问题四步法

**四步流程（课件，红绿交替横幅，依次推进）**

| 步骤 | 名称 | 颜色 |
|------|------|------|
| 1 | **发现异常** | 红 |
| 2 | **优选顺序** | 绿 |
| 3 | **描述现状** | 黄/绿 |
| 4 | **确定目标** | 绿 |

**流程示意**

```
1 发现异常（红）
    ↓
2 优选顺序（绿）
    ↓
3 描述现状（红）
    ↓
4 确定目标（绿）
```

**四步解读**

| 步骤 | 关键词 | 说明 |
|------|--------|------|
| 发现异常 | 发现 | 识别异常现象/偏差 |
| 优选顺序 | 优选 | 多个异常中确定优先处理顺序 |
| 描述现状 | 现状 | 客观描述当前实际情况 |
| 确定目标 | 目标 | 明确期望达到的目标/标准 |

**速记口诀**

> 发现异常 → 优选顺序 → 描述现状 → 确定目标

**与 1.2 四步主流程关系**

| 界定问题四步法 | 对应工具/小节（本章） |
|---------------|---------------------|
| 发现异常 | 2.2 发现异常现象的维度 |
| 优选顺序 | 2.3 优选矩阵 / 2.4 注意事项 |
| 描述现状 | 2.7 白色思考帽 |
| 确定目标 | 2.8 描述期望值的工具 |

**易考点**

- 界定问题四步 = **发现异常 → 优选顺序 → 描述现状 → 确定目标**
- 第一步是**发现异常**（非直接描述现状）；第二步**优选顺序**（多个问题时先排序）
- 第三步**描述现状** + 第四步**确定目标** = 现状 vs 期望（问题=差距）
- 与 1.2 主流程第一步"界定问题"对应，本章四步是其**展开**
- 易错点：顺序不可乱——先**发现**再**优选**，先**现状**再**目标**；第二步是"优选顺序"不是"分析原因"

### 2.2 发现异常现象的维度

**六大维度（课件，左三 + 右三）**

| # | 维度 | 子项 |
|---|------|------|
| 1 | **消费者分析** | 客户行为分析、用户行为分析 |
| 2 | **过往异常分析** | 同比分析、环比分析 |
| 3 | **对标分析** | 竞争对手分析、标杆分析 |
| 4 | **决策者分析** | 决策者期望值分析、专家期望值分析 |
| 5 | **发展趋势分析** | 时间进度分析、KPI 完成率分析 |
| 6 | **环境分析** | 不变中蕴含突变概率分析、环境变化分析 |

**维度分组**

| 分组 | 维度 | 侧重 |
|------|------|------|
| **左（外部/对比）** | 消费者 / 过往异常 / 对标 | 从客户、历史、竞品找异常 |
| **右（内部/趋势）** | 决策者 / 发展趋势 / 环境 | 从期望、进度、环境找异常 |

**各维度解读**

| 维度 | 关键词 | 说明 |
|------|--------|------|
| 消费者分析 | 客户/用户行为 | 从**终端使用者**行为变化发现异常 |
| 过往异常分析 | 同比/环比 | 与**历史同期**或**上期**对比发现异常 |
| 对标分析 | 竞争对手/标杆 | 与**竞品**或**行业标杆**对比发现异常 |
| 决策者分析 | 决策者/专家期望 | 与**领导或专家期望值**对比发现异常 |
| 发展趋势分析 | 时间进度/KPI | 与**计划进度**或 **KPI 完成率**对比发现异常 |
| 环境分析 | 突变概率/环境变化 | 从**外部环境**变化或潜在突变发现异常 |

**易考点**

- 发现异常六大维度 = **消费者 + 过往异常 + 对标 + 决策者 + 发展趋势 + 环境**
- 各维度子项（高频）：
  - 过往异常 → **同比 + 环比**
  - 对标 → **竞争对手 + 标杆**
  - 决策者 → **决策者期望值 + 专家期望值**
  - 发展趋势 → **时间进度 + KPI 完成率**
  - 环境 → **突变概率 + 环境变化**
- 对应 2.1 第一步**发现异常**的具体展开
- 易错点：**同比**（与去年同期比）vs **环比**（与上一期比）勿混淆；**对标**含竞品和标杆两个方向

### 2.3 优选顺序时的工具—优选矩阵

**优选矩阵三维度（课件）**

| 维度 | 子项/含义 | 图标颜色 |
|------|----------|---------|
| **重要性** | 与**目标相关性** | 蓝 |
| **紧急性** | **最后期限** | 橙 |
| **变化趋势** | **恶化 / 不变 / 消亡** | 蓝 |

**三维度解读**

| 维度 | 判断什么 | 说明 |
|------|---------|------|
| **重要性** | 与目标有多相关 | 对目标影响越大，越重要 |
| **紧急性** | 时间压力多大 | 期限越近，越紧急 |
| **变化趋势** | 问题会怎么变 | 恶化→优先；不变→次之；消亡→可延后 |

**《新华字典》定义（课件）**

| 词 | 定义 |
|----|------|
| **重要** | 具有**重大影响或后果**的，有**很大意义**的 |
| **紧急** | 需要**立即行动**，**不容拖延** |
| **变化** | 事物产生**新的状况** |

**变化趋势三态**

| 趋势 | 含义 | 优先度 |
|------|------|--------|
| **恶化** | 问题在加重 | 高（优先处理） |
| **不变** | 问题维持现状 | 中 |
| **消亡** | 问题自行消失 | 低（可延后） |

**易考点**

- 优选矩阵三维度 = **重要性 + 紧急性 + 变化趋势**
- 重要性看**与目标相关性**（非"事情大不大"）
- 紧急性看**最后期限**（非"领导催不催"）
- 变化趋势三态 = **恶化 / 不变 / 消亡**
- 字典定义（高频）：
  - 重要 = 重大影响或后果、很大意义
  - 紧急 = 立即行动、不容拖延
  - 变化 = 产生新状况
- 对应 2.1 第二步**优选顺序**的工具
- 易错点：重要性≠紧急性（重要不紧急 vs 紧急不重要）；变化趋势**恶化**应优先处理

### 2.6 什么是问题？

**问题的定义（课件，红色强调）**

> **问题就是现实与期望之间的差距。**

**概念图（课件）**

```
理想状态（目标状态）  ←——→  现状（现实状态）
              ↓
         差距 = 问题
```

**三要素解读**

| 要素 | 别名 | 含义 |
|------|------|------|
| **理想状态** | 目标状态 / 期望 | 想要达到的标准 |
| **现状** | 现实状态 | 当前实际情况 |
| **差距** | 问题 | 两者之差即为问题 |

**公式表达**

> **问题 = 理想状态（期望）− 现状（现实）**

**易考点**

- 问题定义（高频）= **现实与期望之间的差距**
- 公式：**差距 = 问题**
- 理想状态 = **目标状态/期望**；现状 = **现实状态**
- 与 2.1 四步法呼应：第三步**描述现状** + 第四步**确定目标** → 两者之差即问题
- 与 2.7（白色思考帽描述现状）、2.8（描述期望值工具）直接对应
- 易错点：问题不是"困难"或"麻烦"，而是**可衡量的差距**；没有期望/目标就**无法界定问题**

### 2.8 描述期望值的工具

**SMART 原则（描述期望值/目标状态）**

| 字母 | 英文 | 中文 |
|------|------|------|
| **S** | Specific | **具体的** |
| **M** | Measurable | **可衡量的** |
| **A** | Achievable | **可实现的** |
| **R** | Realistic | **现实的** |
| **T** | Time Bound | **时间要求的** |

**速记口诀**

> S 具体、M 可衡量、A 可实现、R 现实、T 时间要求

**与 2.6 问题定义的关系**

```
理想状态（期望值）= SMART 描述的目标
现状（现实状态）= 白色思考帽描述（2.7）
差距 = 问题（2.6）
```

**易考点**

- 描述期望值工具 = **SMART 原则**
- 本课 SMART 五要素：**Specific / Measurable / Achievable / Realistic / Time Bound**
- 中文：**具体的 / 可衡量的 / 可实现的 / 现实的 / 时间要求的**
- 对应 2.1 第四步**确定目标**、2.6 **理想状态（目标状态）**
- 易错点：本课 **R = Realistic（现实的）**，非 Relevant（相关的）；**A = Achievable（可实现的）**
- 与《认识复盘》SMART 对比：R 不同（本课=现实，复盘课=相关）

### 2.9 问题描述案例

**案例：销售进度问题（三步描述法）**

| 步骤 | 类别 | 内容 |
|------|------|------|
| 01 | **当前状况** | 第一季度销售进度**太慢** |
| 02 | **理想状态** | 第二季度**提高销售进度** |
| 03 | **问题/差距陈述** | 在第一季度的销售进度的基础上**提高销售进度** |

**案例逻辑（对应 2.6 公式）**

```
当前状况（现状）     理想状态（期望）
第一季度销售进度太慢  →  第二季度提高销售进度
              ↓
    问题/差距陈述 = 在Q1基础上提高销售进度
```

**三步描述法解读**

| 步骤 | 对应工具/概念 | 说明 |
|------|-------------|------|
| 01 当前状况 | 2.7 白色思考帽 | 客观描述**现状**（事实） |
| 02 理想状态 | 2.8 SMART 工具 | 描述**期望值/目标** |
| 03 问题/差距陈述 | 2.6 问题定义 | 用一句话表达**差距=问题** |

**易考点**

- 问题描述三步 = **当前状况 → 理想状态 → 问题/差距陈述**
- 案例：现状="Q1 销售进度太慢"；期望="Q2 提高销售进度"；差距="在 Q1 基础上提高销售进度"
- 问题/差距陈述 = 把**现状与期望的差距**用一句话说清楚
- 与 2.6 呼应：**差距 = 问题**；与 2.1 四步法第三步+第四步呼应
- 易错点：问题陈述不是重复现状或期望，而是表达**两者之间的差距/改进方向**

## 三、要因分析

> 本章目录（Part 3）：要因分析四步法 → 头脑风暴 → 结构细化方法/原则 → MECE → 鱼骨图/案例 → 影响圈与关注圈 → 帕累托原则。

### 3.1 要因分析四步法

> 四步法主体流程待截图补充。

#### 内部归因：与人相关的归因法则

**三层阶梯（课件，由浅入深）**

```
原因（深蓝，最短，最上）  ← 最深、最本质
理由（浅蓝，中间）
借口（绿色，最长，最下）  ← 最浅、最常见
```

| 层级 | 名称 | 颜色 | 位置 | 含义 |
|------|------|------|------|------|
| 1（下） | **借口** | 绿 | 最长/最左 | 表面推脱，**非真正要因** |
| 2（中） | **理由** | 浅蓝 | 中等 | 有一定解释力，**尚非根因** |
| 3（上） | **原因** | 深蓝 | 最短/最右 | **真正要因**，需深挖到此 |

**层级解读**

| 对比 | 说明 |
|------|------|
| 借口 vs 理由 vs 原因 | 由浅入深：**借口**（推脱）→ **理由**（解释）→ **原因**（根因） |
| 内部归因 | 与人相关的归因，须区分**真因**与**借口/理由** |
| 分析目标 | 要因分析须穿透**借口**，越过**理由**，找到**原因** |

**易考点**

- 内部归因三层次 = **借口 → 理由 → 原因**（由浅入深）
- **原因**在最上层（最深）；**借口**在最下层（最浅、最常见）
- 要因分析目标：不停留在**借口/理由**，要挖到**原因**
- 与人相关归因时，警惕把**借口当原因**
- 易错点：三者**不是同义词**——借口≠理由≠原因；分析时须**逐层穿透**

### 3.2 列举要素的管理工具—头脑风暴

**头脑风暴的基本法则（七条）**

| # | 法则 | 说明 |
|---|------|------|
| 1 | **轮流发言** | 每人**按顺序**发言，而非自由讨论 |
| 2 | **数量重于质量** | 鼓励**多产出**想法，即使有缺陷 |
| 3 | **鼓励不受约束的意见** | **所有意见**均可接受 |
| 4 | **力求创造性** | 激发**尽可能多的**想法 |
| 5 | **搭便车** | 在他人意见上**叠加、合并**（piggybacking） |
| 6 | **列出所有意见** | 记录者**不得编辑或解读**想法 |
| 7 | **酝酿** | 对列出的意见**花时间思考**，常激发新想法 |

**速记口诀**

> 轮流、数量、不受约束、创造性、搭便车、全列出、酝酿

**易考点**

- 头脑风暴七法则 = **轮流发言 + 数量重于质量 + 鼓励不受约束 + 力求创造性 + 搭便车 + 列出所有意见 + 酝酿**
- **数量重于质量**：先多后精，不急于评判
- **搭便车**：在他人想法上**叠加/合并**，非抄袭
- **列出所有意见**：记录者**不得编辑或解读**（保真）
- **酝酿**：思考已有意见后**再出新想法**（非立即结束）
- 对应 3.1 要因分析四步法中**列举要素**环节的工具
- 易错点：头脑风暴**不是自由讨论**（须**轮流发言**）；记录者角色是**忠实记录**（非筛选/解读）

### 3.3 结构细化的两种方法

**演绎法 vs 归纳法（课件对比）**

| 方法 | 颜色 | 逻辑方向 | 结构特点 |
|------|------|---------|---------|
| **演绎法** | 绿 | 中心思想 → 逐层推导 → 回归中心 | 三个方框**顺序串联**（上下箭头连接） |
| **归纳法** | 蓝 | 多个要点 → 汇总 → 中心思想 | 三个方框**各自独立**，箭头**同时指向**中心思想 |

**演绎法（Deduction）**

```
中心思想 → [要点1] → [要点2] → [要点3] ↩ 中心思想
         （顺序推导，自上而下）
```

- 从**中心思想**出发，**逐层推导**
- 要点之间**有逻辑顺序**（上下箭头串联）
- 最终结论**回归/强化**中心思想

**归纳法（Induction）**

```
[要点1] ──┐
[要点2] ──┼→ 中心思想
[要点3] ──┘
（并列汇总，自下而上）
```

- 多个**独立要点**并列
- 各要点**分别指向**中心思想（无顺序要求）
- 从**具体事实归纳**出中心思想

**对比要点**

| 对比项 | 演绎法 | 归纳法 |
|--------|--------|--------|
| 方向 | **自上而下**（总→分） | **自下而上**（分→总） |
| 要点关系 | **有顺序**（串联） | **无顺序**（并列） |
| 适用 | 论证、推理、因果链 | 分类、汇总、归纳结论 |

**易考点**

- 结构细化两种方法 = **演绎法 + 归纳法**
- 演绎法：**顺序串联**，自上而下，逻辑链推导
- 归纳法：**并列汇总**，自下而上，多要点归一
- 与金字塔原理呼应：演绎=论证链；归纳=分组汇总
- 易错点：演绎法要点**有先后顺序**；归纳法要点**无顺序**、各自独立指向中心

### 3.4 结构细化的原则

**层级结构示意（课件）**

```
        0
        G
    A   B   C
  A1    B1    C1
  A2    B2    C2
  A3    B3    C3
```

**三大原则（红色标注）**

| # | 原则 | 含义 | 对应层级 |
|---|------|------|---------|
| 1 | **上下对应** | 任何一个层次上的原因都必须是其**下一层次原因的概括** | 上层 ↔ 下层（如 G 概括 A/B/C） |
| 2 | **分类清楚** | 每一组中的原因必须属于**同一逻辑范畴** | 同组内（如 A1/A2/A3 同属 A） |
| 3 | **排列递进** | 每一组中的原因都必须按照**逻辑顺序**排列 | 同组内顺序（如 A1→A2→A3） |

**三原则解读**

| 原则 | 关键词 | 反例（违反时） |
|------|--------|--------------|
| 上下对应 | 概括、对应 | 上层原因无法涵盖下层所有要点 |
| 分类清楚 | 同范畴、MECE | 同组内混入不同逻辑类别的项 |
| 排列递进 | 逻辑顺序 | 同组内要点乱序、无递进关系 |

**与 3.3 两种方法关系**

- **演绎法**侧重**排列递进**（顺序推导）
- **归纳法**侧重**分类清楚 + 上下对应**（分组汇总）
- 三原则共同保证结构**清晰、完整、有逻辑**

**易考点**

- 结构细化三原则 = **上下对应 + 分类清楚 + 排列递进**
- 上下对应：上层 = 下层的**概括**（非简单罗列）
- 分类清楚：同组 = **同一逻辑范畴**（与 MECE 3.5 呼应）
- 排列递进：同组内 = **逻辑顺序排列**（与演绎法呼应）
- 易错点：三原则**同时满足**；分类清楚≠随便分组，须**同一逻辑范畴**

### 3.5 MECE 原则

**MECE 全称**

| 字母 | 英文 | 中文 |
|------|------|------|
| **M** | Mutually | **相互** |
| **E** | Exclusive | **排他的** |
| **C** | Collectively | **收集** |
| **E** | Exhaustive | **网罗的** |

**MECE = 相互独立，完全穷尽**（不遗漏、不重复）

**四种分类状态（课件四象限）**

| 状态 | 遗漏？ | 重复？ | 判定 | 示意 |
|------|-------|--------|------|------|
| ✅ 正确 | 否 | 否 | **不遗漏不重复** | A/B/C 完整填满、互不重叠 |
| ❌ 错误 | 否 | 是 | **不遗漏有重复** | A/B/C 填满但 D 与 A/B 重叠 |
| ❌ 错误 | 是 | 否 | **有遗漏不重复** | A/B 之间有空白间隙 |
| ❌ 错误 | 是 | 是 | **有遗漏有重复** | A/B 重叠且留有空隙 |

**MECE 两要求**

| 要求 | 含义 | 反面 |
|------|------|------|
| **Mutually Exclusive（相互独立）** | 各类别**不重复**、不重叠 | 有重复 |
| **Collectively Exhaustive（完全穷尽）** | 各类别**不遗漏**、完整覆盖 | 有遗漏 |

**底部总结（课件）**

> 经营分析师比一般员工更逻辑之处：能够有**【无遗漏无重复】**的思考方法。只会「考虑」而不会 MECE 分析的经营分析师**没有价值**。

**与 3.4 结构细化原则关系**

- MECE 是**分类清楚**原则的具体工具/标准
- 结构细化时，同组分类须满足 MECE

**易考点**

- MECE = **Mutually Exclusive + Collectively Exhaustive**
- 中文：**相互独立（不重复）+ 完全穷尽（不遗漏）**
- 唯一正确状态 = **不遗漏不重复**
- 三种错误：不遗漏有重复 / 有遗漏不重复 / 有遗漏有重复
- 与 3.4 **分类清楚**呼应：同组须**同一逻辑范畴**且 MECE
- 易错点：MECE 两个 E 含义不同（Exclusive=排他，Exhaustive=穷尽）；**Collectively** 译"收集"但含义是** collectively exhaustive = 合起来穷尽**

### 3.8 影响圈与关注圈

**同心圆模型（课件）**

```
┌─────────────────────────┐
│   关切范围（关注圈）      │  ← 外层（蓝灰）
│   ┌─────────────────┐   │
│   │  影响范围（影响圈） │   │  ← 内层（白）
│   └─────────────────┘   │
└─────────────────────────┘
```

**两圈定义**

| 圈层 | 别名 | 含义 |
|------|------|------|
| **关切范围**（外层） | **关注圈** | 一个人**关切和担心**的所有事件 |
| **影响范围**（内层） | **影响圈** | 一个人**可以影响**的所有事情 |

**课件原文**

| 圈层 | 定义 |
|------|------|
| **关切范围（关注圈）** | 一个人的关切范围包含所有他或她**关切和担心**的事件在内 |
| **影响范围（影响圈）** | 一个人的影响范围包括所有他或她**可以影响**的事情 |

**关系与要点**

| 对比项 | 关注圈（关切） | 影响圈（影响） |
|--------|--------------|--------------|
| 范围 | **更大**（外层） | **更小**（内层，被包含） |
| 关键词 | **关切、担心** | **可以影响** |
| 行动导向 | 超出影响圈的部分**无法直接控制** | **应聚焦**此处采取行动 |

**易考点**

- 两圈关系：**影响圈 ⊂ 关注圈**（影响范围在关切范围之内）
- 关注圈 = **关切和担心**的事件；影响圈 = **可以影响**的事情
- 课件用词：**关切范围**（外层）= **关注圈**；**影响范围**（内层）= **影响圈**
- 要因分析/问题解决：应**聚焦影响圈**内可改变的因素，而非仅停留在关注圈
- 与柯维「七个习惯」中 Circle of Concern/Influence 概念一致
- 易错点：关注圈**更大**、影响圈**更小**；**担心 ≠ 能影响**，须区分两圈

### 3.9 选择重点的管理工具—帕累托原则

**起源（课件）**

- **1879 年**，意大利经济学家 **维弗雷多·帕累托**（Vilfredo Pareto）提出
- **80%** 的社会财富由 **20%** 的人占有
- 其余 **80%** 的人只占有 **20%** 的财富

**核心理论**

| 概念 | 中文 | 含义 |
|------|------|------|
| **Vital Few** | **关键的少数** | 少数关键因素产生主要效果 |
| **Trivial Many** | **次要的多数** | 多数次要因素只产生少量效果 |

> 又称 **80/20 法则**、**帕累托原则**（Pareto Principle），广泛应用于社会学和经济学。

**商业应用图示（课件）**

```
产品数量百分比          利润百分比
┌──────────┐          ┌──────────┐
│ 20%的产品 │ ──· · ·→ │ 80%的利润 │  （红段对应）
│ (关键少数)│          │ (主要产出) │
└──────────┘          └──────────┘
```

| 维度 | 少数（20%） | 多数（80%） |
|------|------------|------------|
| 产品 | **20% 的产品** | 80% 的产品 |
| 利润 | 贡献 **80% 的利润** | 仅贡献 20% 的利润 |

**在要因分析中的应用**

- 选择重点时，聚焦**关键的少数**要因（20% 要因 → 80% 效果）
- 与 3.8 影响圈呼应：在**影响圈内**用帕累托找**关键要因**
- 避免在**次要的多数**上耗费过多精力

**易考点**

- 帕累托原则 = **80/20 法则** = **关键的少数 + 次要的多数**
- 提出者：**1879 年**意大利经济学家 **维弗雷多·帕累托**
- 经典比例：**80% 结果来自 20% 原因**（财富/产品/利润等）
- 商业案例：**20% 产品 → 80% 利润**
- 要因分析用途：**选择重点**，聚焦关键要因
- 易错点：不是"20%的人穷80%的人富"的简单记忆，核心是**少数关键因素产生主要效果**；应用于**选重点**而非平均用力

- 与 2.1 界定问题四步法**结构对称**（均为四步、红绿交替）
- 易错点：顺序不可乱——先**备选**再**细化**，**创新**在**确认**之前；第三步是"融入创新"不是"头脑风暴"

### 4.2 设计备选方案的管理工具—优选矩阵

**工具名称：时间、有效性、可行性、成本一览表**

用于 4.1 第一步**建立备选**时，对多个备选方案进行**多维度评估与排序**。

**优选矩阵表头（8 列）**

| 列 | 字段 | 含义 |
|----|------|------|
| 1 | **序号** | 方案编号 |
| 2 | **方案** | 备选方案名称/描述 |
| 3 | **时间** | 实施所需时间评估 |
| 4 | **有效性** | 方案解决问题的**效果**评估 |
| 5 | **可行性** | 方案**能否落地**的评估 |
| 6 | **成本** | 方案所需**资源/费用**评估 |
| 7 | **合计** | 各维度得分**汇总** |
| 8 | **排序** | 按合计得分**排名**，确定优先方案 |

**四评估维度**

| 维度 | 评估什么 |
|------|---------|
| **时间** | 方案实施**快慢**、周期长短 |
| **有效性** | 方案**解决问题**的效果/程度 |
| **可行性** | 方案**能否执行**、条件是否具备 |
| **成本** | 方案所需**人力/物力/财力** |

**使用流程**

```
列出备选方案 → 逐方案评估四维度 → 合计得分 → 排序 → 选定优先方案
```

**与 2.3 优选矩阵对比（易混考点）**

| 对比项 | 2.3 优选矩阵（界定问题） | 4.2 优选矩阵（确认方案） |
|--------|------------------------|------------------------|
| 用途 | **优选顺序**——多个异常/问题先处理哪个 | **设计备选**——多个方案选哪个 |
| 对应步骤 | 2.1 第二步**优选顺序** | 4.1 第一步**建立备选** |
| 三/四维度 | **重要性 + 紧急性 + 变化趋势** | **时间 + 有效性 + 可行性 + 成本** |
| 输出 | 问题处理优先级 | 方案排名/选定 |

**易考点**

- 4.2 优选矩阵 = **时间、有效性、可行性、成本一览表**
- 表头 8 列 = **序号 + 方案 + 时间 + 有效性 + 可行性 + 成本 + 合计 + 排序**
- 四评估维度 = **时间 + 有效性 + 可行性 + 成本**
- 对应 4.1 第一步**建立备选**的管理工具
- 与 2.3 **同名但不同**：2.3 评**问题优先级**（重要性/紧急性/变化趋势）；4.2 评**方案优劣**（时间/有效性/可行性/成本）
- 易错点：勿与 2.3 混淆维度；**有效性**评效果，**可行性**评能否落地，二者不同

### 4.4 可参考的行动词汇示例

细化行动步骤（4.3）时，行动项须以**动词**开头。以下四类行动词汇供参考。

**四大类别**

| # | 类别 | 英文 | 层级 | 说明 |
|---|------|------|------|------|
| 1 | **决策或设定目标** | Decision | 高层 | 批准、规划、决定、授权等 |
| 2 | **执行管理** | Management | 中层 | 监控、执行、评估、改善等 |
| 3 | **专业与支持** | Support | 专业 | 分析、建议、协调、预测等 |
| 4 | **具体或基层工作** | Execute | 基层 | 检查、处理、收集、提交等 |

#### 1. 决策或设定目标（Decision）

| 列1 | 列2 | 列3 | 列4 | 列5 |
|-----|-----|-----|-----|-----|
| 批准 | 指导 | 授权 | 建立 | 制订 |
| 规划 | 决定 | 准备；预备 | 发展 | |

#### 2. 执行管理（Management）

| 列1 | 列2 | 列3 | 列4 | 列5 |
|-----|-----|-----|-----|-----|
| 达成 | 增进 | 评估 | 建立 | 赢得 |
| 评定 | 吸引 | 限制 | 确保 | 维护 |
| 评估；衡量 | 监控 | 取得认同 | 审核 | 找出 |
| 设定 | 执行 | 指明 | 改善 | 标准化 |

#### 3. 专业与支持（Support）

| 列1 | 列2 | 列3 | 列4 | 列5 |
|-----|-----|-----|-----|-----|
| 分析 | 辨明 | 界定 | 建议；提议 | 促使 |
| 建议 | 预测 | 协调 | 解释 | 支援 |

#### 4. 具体或基层工作（Execute）

| 列1 | 列2 | 列3 | 列4 | 列5 |
|-----|-----|-----|-----|-----|
| 检查；检验 | 执行；履行 | 对照 | 提出 | 分配 |
| 处理 | 收集；汇集 | 生产；制造 | 分发 | 进行 |
| 提供 | 获得 | 提交 | 操作；执行 | 供应 |

**层级关系（由高到低）**

```
决策或设定目标（Decision）
        ↓
   执行管理（Management）
        ↓
   专业与支持（Support）
        ↓
  具体或基层工作（Execute）
```

**与 4.3 的关系**

- 4.3 要求行动步骤含**动词/任务/标准/期限**
- 4.4 提供**动词词汇库**，按层级分类选用
- 行动项写法示例：**动词 + 任务内容 + 标准 + 期限**

**易考点**

- 行动词汇四大类 = **决策或设定目标 + 执行管理 + 专业与支持 + 具体或基层工作**
- 英文对应：**Decision / Management / Support / Execute**
- 层级由高到低：Decision → Management → Support → Execute
- 对应 4.1 第二步**细化步骤**、4.3 **动词**要素
- 高频动词举例：
  - 决策层：**批准、规划、决定、授权、制订**
  - 管理层：**监控、执行、评估、改善、标准化**
  - 支持层：**分析、建议、协调、预测、界定**
  - 执行层：**检查、处理、收集、提交、进行**
- 易错点：行动步骤须以**动词开头**（非名词）；不同层级选不同类别动词

### 4.6 有效确认的管理工具

对应 4.1 第四步**有效确认**，含两大管理工具，方向相反、互补使用：

```
  因人而异 ←—— 有效确认 ——→ 有效表达
  （左：因人而异）        （右：有效表达）
```

**两大工具**

| 工具 | 方向 | 图示 | 含义 |
|------|------|------|------|
| **因人而异** | ← 左 | **2×2 矩阵**（四格，红黄框） | 确认方式须**因对象不同而调整** |
| **有效表达** | → 右 | **层级树状图**（组织图结构） | 确认时须**结构化、层次化表达** |

#### 1. 因人而异

**图示：** 2×2 四格矩阵（类似人格/类型分类框架）

| 要点 | 说明 |
|------|------|
| 核心 | 有效确认须**因人而异**，不能一套说法打天下 |
| 应用 | 根据确认对象的**类型/特点/偏好**，选择不同的确认方式 |
| 矩阵含义 | 将对象**分类**后，匹配相应的确认策略 |

#### 2. 有效表达

**图示：** 层级树状结构（顶层→中层→底层，多种形状节点）

```
        ○（顶层：核心结论）
    ┌───┼───┐
   □   ○   △（中层：分类要点）
  ┌┐  ┌┼┐  ┌┐（底层：细节支撑）
```

| 要点 | 说明 |
|------|------|
| 核心 | 确认方案时须**有效表达**，使对方清晰理解 |
| 结构 | **自上而下**：核心结论 → 分类要点 → 细节支撑 |
| 应用 | 将复杂方案**拆解为层次化逻辑**，便于对方确认 |

**两工具关系**

| 维度 | 因人而异 | 有效表达 |
|------|---------|---------|
| 侧重 | **对谁**确认（对象差异） | **怎么**确认（表达结构） |
| 工具 | 2×2 **分类矩阵** | **层级树状**结构 |
| 目标 | 匹配对象，提高接受度 | 逻辑清晰，便于理解确认 |

**易考点**

- 有效确认两大管理工具 = **因人而异 + 有效表达**
- **因人而异**（左）：2×2 矩阵，确认方式**因对象不同而调整**
- **有效表达**（右）：层级树状图，确认时**结构化、层次化表达**
- 对应 4.1 第四步**有效确认**
- 两工具互补：**对象适配**（因人而异）+ **表达清晰**（有效表达）
- 易错点：二者**不是二选一**，而是有效确认的两个维度；有效表达强调**自上而下层级**，非平铺罗列
