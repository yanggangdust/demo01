## 一、什么是问题分析与解决

> 本章目录（Part 1）：管理者角色与解决问题 → 问题分析与解决的步骤 → 问题分析与解决的价值 → 课程目标。

### 1.1 管理者角色与解决问题

**核心观点（左侧竖排）**

> 一位管理者的主要角色是**通过别人来完成工作**！

**管理者角色流程图（课件）**

```
管理者 ──→ 解决问题的能力 ──┬→ 人员管理 ──┐
                            └→ 事务成果 ←─┘
```

| 要素 | 含义 |
|------|------|
| **管理者** | 管理工作的主体 |
| **解决问题的能力** | 管理者的核心能力（中间枢纽） |
| **人员管理** | 管理输出之一：管人 |
| **事务成果** | 管理输出之二：管事/出成果 |

**流程关系**

- 管理者靠**解决问题的能力**，实现**人员管理**和**事务成果**
- **人员管理 → 事务成果**：管人是为了出成果（右侧弧形箭头）

**底部总结（红色横幅）**

> 优秀的管理者，就是**永远在条件不充分具备的情况下**，带领团队**出色完成任务**的人

**易考点**

- 管理者主要角色 = **通过别人来完成工作**（非自己亲力亲为）
- 管理者核心能力 = **解决问题的能力**（连接角色与两大输出）
- 两大管理输出 = **人员管理 + 事务成果**
- 关系链：管理者 → 解决问题能力 → 人员管理 → 事务成果
- 优秀管理者定义：**条件不充分**时仍能**带领团队出色完成任务**
- 易错点：管理者≠自己做事，而是**通过别人**；解决问题能力是**枢纽**，不是可有可无

### 1.2 问题分析与解决的步骤

**四步循环流程（课件，顺时针，中心：系统思维）**

```
            1 界定问题
               ↑
4 落地执行 ← [系统思维] → 2 要因分析
               ↓
            3 确认方案
```

**中心核心**

| 要素 | 含义 |
|------|------|
| **系统思维** | 问题分析与解决的基础思维（贯穿四步） |

**四步清单**

| 步骤 | 名称 | 位置 | 图标含义 |
|------|------|------|---------|
| 1 | **界定问题** | 上 | 框定/定义问题范围 |
| 2 | **要因分析** | 右 | 分析关键要因/根因 |
| 3 | **确认方案** | 下 | 确定解决方案 |
| 4 | **落地执行** | 左 | 执行落地 |

**与课程五章对应**

| 步骤 | 对应章节 |
|------|---------|
| 1 界定问题 | 第二章 |
| 2 要因分析 | 第三章 |
| 3 确认方案 | 第四章 |
| 4 落地执行 | 第五章 |

**速记口诀**

> 界定 → 要因 → 确认 → 落地（以**系统思维**为核心）

**易考点**

- 问题分析与解决四步 = **界定问题 → 要因分析 → 确认方案 → 落地执行**（顺时针）
- 中心核心 = **系统思维**（非某一步，而是贯穿全程的基础思维）
- 四步与课程第二~五章**一一对应**
- 流程特点：**循环/迭代**（四步首尾相连，非一次性线性）
- 易错点：第一步是**界定问题**（非直接分析原因）；核心是**系统思维**（非"分析问题"本身）

### 1.3 问题分析与解决的价值

**中心核心：系统思维**

四价值围绕**系统思维**展开：

```
        有始有终              组织效率
           ╲                ╱
            ╲  系统思维  ╱
             ╲          ╱
        由繁到简        整体致胜
```

**四大价值**

| # | 价值 | 关键词 | 详解 |
|---|------|--------|------|
| 1 | **有始有终** | 四步法整体推进 | 用四步法**从头到尾**推进，不半途而废 |
| 2 | **由繁到简** | 初学繁琐→熟练省时 | **初学**觉得步骤繁琐；**熟练后**节约时间 |
| 3 | **组织效率** | 统一行动、降沟通成本 | 组织**统一行动**，**减少沟通成本**，**提升整体效率** |
| 4 | **整体致胜** | 局部→全面→系统致胜 | 由**局部/某个点**取胜，进而**全面致胜、系统致胜** |

**速记口诀**

> 有始有终、由繁到简、组织效率、整体致胜

**易考点**

- 问题分析与解决四大价值 = **有始有终 + 由繁到简 + 组织效率 + 整体致胜**
- 均以**系统思维**为中心
- **有始有终**：四步法**整体推进**（非跳步）
- **由繁到简**：**初学繁琐 vs 熟练省时**（对比考点）
- **组织效率**：**统一行动 + 减少沟通成本 + 提升效率**
- **整体致胜**：**局部点取胜 → 全面致胜 → 系统致胜**（递进关系）
- 与 1.2 呼应：有始有终对应**四步法**；整体致胜对应**系统思维**
- 易错点："由繁到简"不是步骤变少，而是**熟练后效率提升**；整体致胜强调**系统**而非单点

## 二、界定问题

> 本章目录（Part 2）：界定问题四步法 → 发现异常现象维度 → 优选矩阵 → 优选矩阵注意事项 → 是问题吗 → 什么是问题 → 白色思考帽 → 描述期望值工具 → 问题描述案例。

### 2.1 界定问题四步法

**四步流程（课件，红绿交替横幅，依次推进）**

| 步骤 | 名称 | 颜色 |
|------|------|------|
| 1 | **发现异常** | 红 |
| 2 | **优选顺序** | 绿 |
| 3 | **描述现状** | 黄/绿 |
| 4 | **确定目标** | 绿 |

**流程示意**

```
1 发现异常（红）
    ↓
2 优选顺序（绿）
    ↓
3 描述现状（红）
    ↓
4 确定目标（绿）
```

**四步解读**

| 步骤 | 关键词 | 说明 |
|------|--------|------|
| 发现异常 | 发现 | 识别异常现象/偏差 |
| 优选顺序 | 优选 | 多个异常中确定优先处理顺序 |
| 描述现状 | 现状 | 客观描述当前实际情况 |
| 确定目标 | 目标 | 明确期望达到的目标/标准 |

**速记口诀**

> 发现异常 → 优选顺序 → 描述现状 → 确定目标

**与 1.2 四步主流程关系**

| 界定问题四步法 | 对应工具/小节（本章） |
|---------------|---------------------|
| 发现异常 | 2.2 发现异常现象的维度 |
| 优选顺序 | 2.3 优选矩阵 / 2.4 注意事项 |
| 描述现状 | 2.7 白色思考帽 |
| 确定目标 | 2.8 描述期望值的工具 |

**易考点**

- 界定问题四步 = **发现异常 → 优选顺序 → 描述现状 → 确定目标**
- 第一步是**发现异常**（非直接描述现状）；第二步**优选顺序**（多个问题时先排序）
- 第三步**描述现状** + 第四步**确定目标** = 现状 vs 期望（问题=差距）
- 与 1.2 主流程第一步"界定问题"对应，本章四步是其**展开**
- 易错点：顺序不可乱——先**发现**再**优选**，先**现状**再**目标**；第二步是"优选顺序"不是"分析原因"

### 2.2 发现异常现象的维度

**六大维度（课件，左三 + 右三）**

| # | 维度 | 子项 |
|---|------|------|
| 1 | **消费者分析** | 客户行为分析、用户行为分析 |
| 2 | **过往异常分析** | 同比分析、环比分析 |
| 3 | **对标分析** | 竞争对手分析、标杆分析 |
| 4 | **决策者分析** | 决策者期望值分析、专家期望值分析 |
| 5 | **发展趋势分析** | 时间进度分析、KPI 完成率分析 |
| 6 | **环境分析** | 不变中蕴含突变概率分析、环境变化分析 |

**维度分组**

| 分组 | 维度 | 侧重 |
|------|------|------|
| **左（外部/对比）** | 消费者 / 过往异常 / 对标 | 从客户、历史、竞品找异常 |
| **右（内部/趋势）** | 决策者 / 发展趋势 / 环境 | 从期望、进度、环境找异常 |

**各维度解读**

| 维度 | 关键词 | 说明 |
|------|--------|------|
| 消费者分析 | 客户/用户行为 | 从**终端使用者**行为变化发现异常 |
| 过往异常分析 | 同比/环比 | 与**历史同期**或**上期**对比发现异常 |
| 对标分析 | 竞争对手/标杆 | 与**竞品**或**行业标杆**对比发现异常 |
| 决策者分析 | 决策者/专家期望 | 与**领导或专家期望值**对比发现异常 |
| 发展趋势分析 | 时间进度/KPI | 与**计划进度**或 **KPI 完成率**对比发现异常 |
| 环境分析 | 突变概率/环境变化 | 从**外部环境**变化或潜在突变发现异常 |

**易考点**

- 发现异常六大维度 = **消费者 + 过往异常 + 对标 + 决策者 + 发展趋势 + 环境**
- 各维度子项（高频）：
  - 过往异常 → **同比 + 环比**
  - 对标 → **竞争对手 + 标杆**
  - 决策者 → **决策者期望值 + 专家期望值**
  - 发展趋势 → **时间进度 + KPI 完成率**
  - 环境 → **突变概率 + 环境变化**
- 对应 2.1 第一步**发现异常**的具体展开
- 易错点：**同比**（与去年同期比）vs **环比**（与上一期比）勿混淆；**对标**含竞品和标杆两个方向

### 2.3 优选顺序时的工具—优选矩阵

**优选矩阵三维度（课件）**

| 维度 | 子项/含义 | 图标颜色 |
|------|----------|---------|
| **重要性** | 与**目标相关性** | 蓝 |
| **紧急性** | **最后期限** | 橙 |
| **变化趋势** | **恶化 / 不变 / 消亡** | 蓝 |

**三维度解读**

| 维度 | 判断什么 | 说明 |
|------|---------|------|
| **重要性** | 与目标有多相关 | 对目标影响越大，越重要 |
| **紧急性** | 时间压力多大 | 期限越近，越紧急 |
| **变化趋势** | 问题会怎么变 | 恶化→优先；不变→次之；消亡→可延后 |

**《新华字典》定义（课件）**

| 词 | 定义 |
|----|------|
| **重要** | 具有**重大影响或后果**的，有**很大意义**的 |
| **紧急** | 需要**立即行动**，**不容拖延** |
| **变化** | 事物产生**新的状况** |

**变化趋势三态**

| 趋势 | 含义 | 优先度 |
|------|------|--------|
| **恶化** | 问题在加重 | 高（优先处理） |
| **不变** | 问题维持现状 | 中 |
| **消亡** | 问题自行消失 | 低（可延后） |

**易考点**

- 优选矩阵三维度 = **重要性 + 紧急性 + 变化趋势**
- 重要性看**与目标相关性**（非"事情大不大"）
- 紧急性看**最后期限**（非"领导催不催"）
- 变化趋势三态 = **恶化 / 不变 / 消亡**
- 字典定义（高频）：
  - 重要 = 重大影响或后果、很大意义
  - 紧急 = 立即行动、不容拖延
  - 变化 = 产生新状况
- 对应 2.1 第二步**优选顺序**的工具
- 易错点：重要性≠紧急性（重要不紧急 vs 紧急不重要）；变化趋势**恶化**应优先处理

### 2.6 什么是问题？

**问题的定义（课件，红色强调）**

> **问题就是现实与期望之间的差距。**

**概念图（课件）**

```
理想状态（目标状态）  ←——→  现状（现实状态）
              ↓
         差距 = 问题
```

**三要素解读**

| 要素 | 别名 | 含义 |
|------|------|------|
| **理想状态** | 目标状态 / 期望 | 想要达到的标准 |
| **现状** | 现实状态 | 当前实际情况 |
| **差距** | 问题 | 两者之差即为问题 |

**公式表达**

> **问题 = 理想状态（期望）− 现状（现实）**

**易考点**

- 问题定义（高频）= **现实与期望之间的差距**
- 公式：**差距 = 问题**
- 理想状态 = **目标状态/期望**；现状 = **现实状态**
- 与 2.1 四步法呼应：第三步**描述现状** + 第四步**确定目标** → 两者之差即问题
- 与 2.7（白色思考帽描述现状）、2.8（描述期望值工具）直接对应
- 易错点：问题不是"困难"或"麻烦"，而是**可衡量的差距**；没有期望/目标就**无法界定问题**

### 2.8 描述期望值的工具

**SMART 原则（描述期望值/目标状态）**

| 字母 | 英文 | 中文 |
|------|------|------|
| **S** | Specific | **具体的** |
| **M** | Measurable | **可衡量的** |
| **A** | Achievable | **可实现的** |
| **R** | Realistic | **现实的** |
| **T** | Time Bound | **时间要求的** |

**速记口诀**

> S 具体、M 可衡量、A 可实现、R 现实、T 时间要求

**与 2.6 问题定义的关系**

```
理想状态（期望值）= SMART 描述的目标
现状（现实状态）= 白色思考帽描述（2.7）
差距 = 问题（2.6）
```

**易考点**

- 描述期望值工具 = **SMART 原则**
- 本课 SMART 五要素：**Specific / Measurable / Achievable / Realistic / Time Bound**
- 中文：**具体的 / 可衡量的 / 可实现的 / 现实的 / 时间要求的**
- 对应 2.1 第四步**确定目标**、2.6 **理想状态（目标状态）**
- 易错点：本课 **R = Realistic（现实的）**，非 Relevant（相关的）；**A = Achievable（可实现的）**
- 与《认识复盘》SMART 对比：R 不同（本课=现实，复盘课=相关）

### 2.9 问题描述案例

**案例：销售进度问题（三步描述法）**

| 步骤 | 类别 | 内容 |
|------|------|------|
| 01 | **当前状况** | 第一季度销售进度**太慢** |
| 02 | **理想状态** | 第二季度**提高销售进度** |
| 03 | **问题/差距陈述** | 在第一季度的销售进度的基础上**提高销售进度** |

**案例逻辑（对应 2.6 公式）**

```
当前状况（现状）     理想状态（期望）
第一季度销售进度太慢  →  第二季度提高销售进度
              ↓
    问题/差距陈述 = 在Q1基础上提高销售进度
```

**三步描述法解读**

| 步骤 | 对应工具/概念 | 说明 |
|------|-------------|------|
| 01 当前状况 | 2.7 白色思考帽 | 客观描述**现状**（事实） |
| 02 理想状态 | 2.8 SMART 工具 | 描述**期望值/目标** |
| 03 问题/差距陈述 | 2.6 问题定义 | 用一句话表达**差距=问题** |

**易考点**

- 问题描述三步 = **当前状况 → 理想状态 → 问题/差距陈述**
- 案例：现状="Q1 销售进度太慢"；期望="Q2 提高销售进度"；差距="在 Q1 基础上提高销售进度"
- 问题/差距陈述 = 把**现状与期望的差距**用一句话说清楚
- 与 2.6 呼应：**差距 = 问题**；与 2.1 四步法第三步+第四步呼应
- 易错点：问题陈述不是重复现状或期望，而是表达**两者之间的差距/改进方向**

### 3.2 列举要素的管理工具—头脑风暴

**头脑风暴的基本法则（七条）**

| # | 法则 | 说明 |
|---|------|------|
| 1 | **轮流发言** | 每人**按顺序**发言，而非自由讨论 |
| 2 | **数量重于质量** | 鼓励**多产出**想法，即使有缺陷 |
| 3 | **鼓励不受约束的意见** | **所有意见**均可接受 |
| 4 | **力求创造性** | 激发**尽可能多的**想法 |
| 5 | **搭便车** | 在他人意见上**叠加、合并**（piggybacking） |
| 6 | **列出所有意见** | 记录者**不得编辑或解读**想法 |
| 7 | **酝酿** | 对列出的意见**花时间思考**，常激发新想法 |

**速记口诀**

> 轮流、数量、不受约束、创造性、搭便车、全列出、酝酿

**易考点**

- 头脑风暴七法则 = **轮流发言 + 数量重于质量 + 鼓励不受约束 + 力求创造性 + 搭便车 + 列出所有意见 + 酝酿**
- **数量重于质量**：先多后精，不急于评判
- **搭便车**：在他人想法上**叠加/合并**，非抄袭
- **列出所有意见**：记录者**不得编辑或解读**（保真）
- **酝酿**：思考已有意见后**再出新想法**（非立即结束）
- 对应 3.1 要因分析四步法中**列举要素**环节的工具
- 易错点：头脑风暴**不是自由讨论**（须**轮流发言**）；记录者角色是**忠实记录**（非筛选/解读）

### 3.3 结构细化的两种方法

**演绎法 vs 归纳法（课件对比）**

| 方法 | 颜色 | 逻辑方向 | 结构特点 |
|------|------|---------|---------|
| **演绎法** | 绿 | 中心思想 → 逐层推导 → 回归中心 | 三个方框**顺序串联**（上下箭头连接） |
| **归纳法** | 蓝 | 多个要点 → 汇总 → 中心思想 | 三个方框**各自独立**，箭头**同时指向**中心思想 |

**演绎法（Deduction）**

```
中心思想 → [要点1] → [要点2] → [要点3] ↩ 中心思想
         （顺序推导，自上而下）
```

- 从**中心思想**出发，**逐层推导**
- 要点之间**有逻辑顺序**（上下箭头串联）
- 最终结论**回归/强化**中心思想

**归纳法（Induction）**

```
[要点1] ──┐
[要点2] ──┼→ 中心思想
[要点3] ──┘
（并列汇总，自下而上）
```

- 多个**独立要点**并列
- 各要点**分别指向**中心思想（无顺序要求）
- 从**具体事实归纳**出中心思想

**对比要点**

| 对比项 | 演绎法 | 归纳法 |
|--------|--------|--------|
| 方向 | **自上而下**（总→分） | **自下而上**（分→总） |
| 要点关系 | **有顺序**（串联） | **无顺序**（并列） |
| 适用 | 论证、推理、因果链 | 分类、汇总、归纳结论 |

**易考点**

- 结构细化两种方法 = **演绎法 + 归纳法**
- 演绎法：**顺序串联**，自上而下，逻辑链推导
- 归纳法：**并列汇总**，自下而上，多要点归一
- 与金字塔原理呼应：演绎=论证链；归纳=分组汇总
- 易错点：演绎法要点**有先后顺序**；归纳法要点**无顺序**、各自独立指向中心
