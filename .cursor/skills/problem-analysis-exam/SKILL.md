## 复习互动方式

1. **默写**：某一整块（如五步法流程 / 分析工具 / 方案确认步骤）
2. **对比**：常见方法差异（如 5why vs 鱼骨图、界定问题 vs 要因分析）
3. **抽问**：随机出简答/判断
4. **纠错**：用户口述，指出遗漏与易错点

回答时：先结论再展开；中文作答；紧扣本 skill，不擅自扩展成无关百科。考试时用户要求「只给答案」则只列要点。
