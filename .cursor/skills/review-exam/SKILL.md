### 1.1 什么是复盘

#### 复盘的定义与起源

- **本义**：围棋术语，指对局结束后**重演整盘棋**，研究对局过程
- **引申义**：任务完成后，**从头到尾重新梳理一遍**整个过程
- **目的**：
  - 持续**验证和纠正**目标
  - 找出**原因/理由**
  - 分析结果（**算账**）
  - 提升**认识**
  - 总结**规律/法则**

#### 美军 AAR（After Action Review）

- **定义**：围绕**绩效表现**对一次事件进行的**专业讨论**
- **核心**：帮助参与者**自己发现**发生了什么、为什么发生
- **目标**：
  - **保持优势**
  - **改正缺点**

**易考点**

| 概念 | 要点 |
|------|------|
| 复盘本义 | **围棋**术语，重演对局研究过程 |
| AAR 全称 | **After Action Review**（行动后反思） |
| AAR 核心 | 围绕**绩效表现**；参与者**自己发现** |
| AAR 目标 | 保持优势 + 改正缺点 |

### 1.2 复盘的目的

**三条要点（课件）**

1. 复盘是**行动后的深刻反思和经验总结**
2. 复盘是**提升组织智慧**的手段
3. 复盘是一个**不断学习、总结、反思、提炼和持续提高**的过程

**三角关系图（复盘 → 沉淀 → 创新）**

```
            复盘（Review）
           /            \
     → 沉淀            创新 ←
       (Accumulation)  (Innovation)
```

| 概念 | 空间维度含义 |
|------|--------------|
| **沉淀** | 组织**效率**来源于：沉淀 |
| **创新** | 组织**价值**意味着：创新 |

**易考点**

| 项 | 内容 |
|----|------|
| 复盘定位 | 行动后的**反思 + 经验总结** |
| 作用 | 提升**组织智慧** |
| 过程属性 | 学习→总结→反思→提炼→**持续提高** |
| 三角关系 | 复盘 → 沉淀（效率）/ 创新（价值） |

### 1.4 复盘的类型

**分类矩阵（按 规模 × 对象）**

| 对象 \ 规模 | 个人 | 团队 | 跨部门 |
|--------------|------|------|--------|
| **活动/事件** | 个人复盘 | 团队复盘 | 团队复盘 |
| **项目** | 个人复盘 | 项目复盘 | 项目复盘 |
| **经营/战略** | NA | NA | **战略复盘** |

**四种复盘类型**

| 类型 | 适用规模 | 适用对象 |
|------|----------|----------|
| **个人复盘** | 个人 | 活动/事件、项目 |
| **团队复盘** | 团队、跨部门 | 活动/事件 |
| **项目复盘** | 团队、跨部门 | 项目 |
| **战略复盘** | 跨部门 | 经营/战略 |

**易考点**

- 个人 + 经营/战略 = **NA**（不适用）
- 团队 + 经营/战略 = **NA**
- **战略复盘** 仅在**跨部门 + 经营/战略**场景
- 团队/跨部门 + 活动/事件 → **团队复盘**
- 团队/跨部门 + 项目 → **项目复盘**

### 1.5 正式复盘与非正式复盘

**流程对比**

| 步骤 | 正式复盘（蓝） | 非正式复盘（橙） |
|------|----------------|------------------|
| 1 | **回顾预期目标** | ❌ 跳过 |
| 2 | **回顾过程 / 评估结果** | **评估结果**（不强调回顾过程） |
| 3 | 根因分析 / 关键成功要素 | 根因分析 / 关键成功要素 |
| 4 | 经验教训 / 改进计划 | 经验教训 / 改进计划 |

**相同点**

- 后两步一致：**根因分析/关键成功要素** + **经验教训/改进计划**

**不同点**

| 对比项 | 正式复盘 | 非正式复盘 |
|--------|----------|------------|
| **回顾目标** | ✅ 有 | ❌ 无 |
| **回顾过程** | ✅ 有 | ❌ 无（只评估结果） |
| 流程 | 完整四步 | 精简（省目标、省过程回顾） |

**易考点**

- 非正式复盘**省略**：回顾预期目标、回顾过程
- 两者**共有**：根因分析 + 经验教训/改进计划
- 正式复盘更**完整严谨**；非正式复盘更**轻量**
