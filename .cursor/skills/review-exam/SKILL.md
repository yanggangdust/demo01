## 一、什么是复盘（原理类型）

> 本章目录：复盘定义 → 目的 → 适用事件 → 类型 → 正式/非正式 → 与工作总结区别 → 七大特点。

### 1.1 什么是复盘

#### 复盘的定义与起源

- **本义**：围棋术语，指对局结束后**重演整盘棋**，研究对局过程
- **引申义**：任务完成后，**从头到尾重新梳理一遍**整个过程
- **目的**：
  - 持续**验证和纠正**目标
  - 找出**原因/理由**
  - 分析结果（**算账**）
  - 提升**认识**
  - 总结**规律/法则**

#### 美军 AAR（After Action Review）

- **定义**：围绕**绩效表现**对一次事件进行的**专业讨论**
- **核心**：帮助参与者**自己发现**发生了什么、为什么发生
- **目标**：
  - **保持优势**
  - **改正缺点**

**易考点**

| 概念 | 要点 |
|------|------|
| 复盘本义 | **围棋**术语，重演对局研究过程 |
| AAR 全称 | **After Action Review**（行动后反思） |
| AAR 核心 | 围绕**绩效表现**；参与者**自己发现** |
| AAR 目标 | 保持优势 + 改正缺点 |

### 1.2 复盘的目的

**三条要点（课件）**

1. 复盘是**行动后的深刻反思和经验总结**
2. 复盘是**提升组织智慧**的手段
3. 复盘是一个**不断学习、总结、反思、提炼和持续提高**的过程

**三角关系图（复盘 → 沉淀 → 创新）**

```
            复盘（Review）
           /            \
     → 沉淀            创新 ←
       (Accumulation)  (Innovation)
```

| 概念 | 空间维度含义 |
|------|--------------|
| **沉淀** | 组织**效率**来源于：沉淀 |
| **创新** | 组织**价值**意味着：创新 |

**易考点**

| 项 | 内容 |
|----|------|
| 复盘定位 | 行动后的**反思 + 经验总结** |
| 作用 | 提升**组织智慧** |
| 过程属性 | 学习→总结→反思→提炼→**持续提高** |
| 三角关系 | 复盘 → 沉淀（效率）/ 创新（价值） |

### 1.4 复盘的类型

**分类矩阵（按 规模 × 对象）**

| 对象 \ 规模 | 个人 | 团队 | 跨部门 |
|--------------|------|------|--------|
| **活动/事件** | 个人复盘 | 团队复盘 | 团队复盘 |
| **项目** | 个人复盘 | 项目复盘 | 项目复盘 |
| **经营/战略** | NA | NA | **战略复盘** |

**四种复盘类型**

| 类型 | 适用规模 | 适用对象 |
|------|----------|----------|
| **个人复盘** | 个人 | 活动/事件、项目 |
| **团队复盘** | 团队、跨部门 | 活动/事件 |
| **项目复盘** | 团队、跨部门 | 项目 |
| **战略复盘** | 跨部门 | 经营/战略 |

**易考点**

- 个人 + 经营/战略 = **NA**（不适用）
- 团队 + 经营/战略 = **NA**
- **战略复盘** 仅在**跨部门 + 经营/战略**场景
- 团队/跨部门 + 活动/事件 → **团队复盘**
- 团队/跨部门 + 项目 → **项目复盘**

### 1.5 正式复盘与非正式复盘

**流程对比**

| 步骤 | 正式复盘（蓝） | 非正式复盘（橙） |
|------|----------------|------------------|
| 1 | **回顾预期目标** | ❌ 跳过 |
| 2 | **回顾过程 / 评估结果** | **评估结果**（不强调回顾过程） |
| 3 | 根因分析 / 关键成功要素 | 根因分析 / 关键成功要素 |
| 4 | 经验教训 / 改进计划 | 经验教训 / 改进计划 |

**相同点**

- 后两步一致：**根因分析/关键成功要素** + **经验教训/改进计划**

**不同点**

| 对比项 | 正式复盘 | 非正式复盘 |
|--------|----------|------------|
| **回顾目标** | ✅ 有 | ❌ 无 |
| **回顾过程** | ✅ 有 | ❌ 无（只评估结果） |
| 流程 | 完整四步 | 精简（省目标、省过程回顾） |

**易考点**

- 非正式复盘**省略**：回顾预期目标、回顾过程
- 两者**共有**：根因分析 + 经验教训/改进计划
- 正式复盘更**完整严谨**；非正式复盘更**轻量**

1. **结构化**
2. **团队化**
3. **学习为导向**
4. **影响重大的事件**

## 二、复盘有什么价值（五大价值）

> 本章目录：复盘与 3721 原则 → 为什么要复盘（五大价值）→ 复盘的价值。

### 2.1 复盘与 3721 原则

**提升能力的 "7-2-1" 原则**

| 来源 | 占比 | 说明 |
|------|------|------|
| **工作** | **70%** | 经验来自工作实践 |
| **向他人学习** | **20%** | 从其他人身上学习 |
| **正规学习** | **10%** | 课堂/培训等正规学习 |

**图示三场景（课件）**

| 场景 | 占比 | 内容 |
|------|------|------|
| 课堂培训 | 10% | 正规学习（如管理能力培训） |
| 向他人学习 | 20% | 观察、交流、协作 |
| 工作实践 | 70% | 边工作、边学习、边总结、边应用 |

**行动口号（课件）**

> **边工作 边学习 边总结 边应用**

**易考点**

- 7-2-1 = **70% 工作 + 20% 向他人学 + 10% 正规学习**
- **工作实践**是能力提升最主要来源（70%）
- 复盘属于**工作总结**环节，对应 70% 中的"边总结"

### 2.2 为什么要复盘（五大价值）

**四象限（课件图示）**

| 象限 | 内容 |
|------|------|
| 左上（蓝） | **知其然，知其所以然** |
| 右上（深绿） | **不再犯同样的错误** |
| 左下（亮绿） | **总结规律，固化流程** |
| 右下（橙） | **传承经验，提升能力** |

**总结语（红色横幅）**

> **把失败转化为财富，把成功转化为能力**

**五大价值完整列表**

1. 知其然，知其所以然
2. 传承经验，提升能力
3. 不再犯同样的错误
4. 总结规律，固化流程
5. 知识管理中心（经验与教训）

**价值 1 详解：知其然，知其所以然 — 2×2 矩阵**

> 横轴：**绩效**（差 → 好）；纵轴：**学习效果**（差 → 好）

| | 绩效差 | 绩效好 |
|---|--------|--------|
| **学习效果好** | **有意义的失败** | **期望的成功** |
| **学习效果差** | **彻底失败** | **无意义的成功** |

**四象限解读**

| 象限 | 含义 |
|------|------|
| **期望的成功**（绩效好+学习好） | 理想状态：成功且知其所以然，可复制 |
| **有意义的失败**（绩效差+学习好） | 失败但有学习，可为未来成功铺路 |
| **无意义的成功**（绩效好+学习差） | 靠运气成功，不知原因，难复制 |
| **彻底失败**（绩效差+学习差） | 失败且无学习 |

**总结语（红色横幅）**

> 区分"**有意义的失败**"与"**无意义的成功**"

**易考点**

- 复盘目标：向"**期望的成功**"靠拢
- 关键区分：**有意义的失败** vs **无意义的成功**
- 学习效果是纵轴；绩效是横轴（勿混淆）

**价值 2 详解：传承经验，提升能力 — 经验增长曲线**

> 坐标轴：横轴 **时间**，纵轴 **经验**

| 曲线 | 形态 | 含义 |
|------|------|------|
| **期望的状况**（绿色虚线） | **阶梯式上升** | 经验**累积**，每个新阶段从上一阶段结束处继续 |
| **当前的状况**（绿色实线弧） | **周期性归零** | 经验获得但未传递，每次项目/个人都**从零开始** |

**总结语（红色横幅）**

> 如果经验不能有效传递，每个项目，每个人都接近于"**从零开始**"

**易考点**

- 复盘 = 让经验**累积传递**，避免"从零开始"
- 期望：**阶梯式**增长；当前：**周期性归零**
- 与价值1矩阵呼应：有意义的失败/成功都要**沉淀为可传递经验**

**价值 3 详解：不再犯同样的错误 — 循环流程**

```
        纠正错误（蓝）
         ↑        ↓
   分享教训（橙）← 吸取教训（绿）
```

| 步骤 | 颜色 | 含义 |
|------|------|------|
| **纠正错误** | 蓝 | 发现并修正错误 |
| **吸取教训** | 绿 | 从错误中学习 |
| **分享教训** | 橙 | 将教训分享给团队，避免重复 |

**循环关系**：纠正错误 → 吸取教训 → 分享教训 → 纠正错误（闭环）

**总结语（红色横幅）**

> 不宽容失败的组织，将会失去创新和活力，走向僵化。宁肯不干，不可做错

**易考点**

- 三步循环：**纠正 → 吸取 → 分享**（闭环防重犯）
- 文化层面：组织需**宽容失败**以保持创新活力
- "宁肯不干，不可做错" 是需警惕的僵化心态

**价值 4 详解：总结规律，固化流程 — 制度决策流程**

```
是否有制度？
  ├─ 是 → 遵照执行 → 结果是否理想？
  │                       ├─ 是 → 结束
  │                       └─ 否 → 想办法先做起来
  └─ 否 → 想办法先做起来 → 想办法先做起来 → 制定/修订
```

**流程解读**

| 决策/动作 | 含义 |
|-----------|------|
| **是否有制度？** | 判断现有流程/规范是否存在 |
| **遵照执行** | 有制度则按制度执行 |
| **结果是否理想？** | 执行后评估效果 |
| **想办法先做起来** | 无制度或效果不佳时，先实践 |
| **制定/修订** | 实践成熟后，固化/修订制度 |

**易考点**

- 有制度 → **遵照执行** → 理想则**结束**，不理想则**先做起来**
- 无制度 → **先做起来** → 成熟后**制定/修订**
- 核心思想：**先实践后固化**，避免空想制度
