## 一、什么是复盘（原理类型）

> 本章目录：复盘定义 → 目的 → 适用事件 → 类型 → 正式/非正式 → 与工作总结区别 → 七大特点。

### 1.1 什么是复盘

#### 复盘的定义与起源

- **本义**：围棋术语，指对局结束后**重演整盘棋**，研究对局过程
- **引申义**：任务完成后，**从头到尾重新梳理一遍**整个过程
- **目的**：
  - 持续**验证和纠正**目标
  - 找出**原因/理由**
  - 分析结果（**算账**）
  - 提升**认识**
  - 总结**规律/法则**

#### 美军 AAR（After Action Review）

- **定义**：围绕**绩效表现**对一次事件进行的**专业讨论**
- **核心**：帮助参与者**自己发现**发生了什么、为什么发生
- **目标**：
  - **保持优势**
  - **改正缺点**

**易考点**

| 概念 | 要点 |
|------|------|
| 复盘本义 | **围棋**术语，重演对局研究过程 |
| AAR 全称 | **After Action Review**（行动后反思） |
| AAR 核心 | 围绕**绩效表现**；参与者**自己发现** |
| AAR 目标 | 保持优势 + 改正缺点 |

### 1.2 复盘的目的

**三条要点（课件）**

1. 复盘是**行动后的深刻反思和经验总结**
2. 复盘是**提升组织智慧**的手段
3. 复盘是一个**不断学习、总结、反思、提炼和持续提高**的过程

**三角关系图（复盘 → 沉淀 → 创新）**

```
            复盘（Review）
           /            \
     → 沉淀            创新 ←
       (Accumulation)  (Innovation)
```

| 概念 | 空间维度含义 |
|------|--------------|
| **沉淀** | 组织**效率**来源于：沉淀 |
| **创新** | 组织**价值**意味着：创新 |

**易考点**

| 项 | 内容 |
|----|------|
| 复盘定位 | 行动后的**反思 + 经验总结** |
| 作用 | 提升**组织智慧** |
| 过程属性 | 学习→总结→反思→提炼→**持续提高** |
| 三角关系 | 复盘 → 沉淀（效率）/ 创新（价值） |

### 1.4 复盘的类型

**分类矩阵（按 规模 × 对象）**

| 对象 \ 规模 | 个人 | 团队 | 跨部门 |
|--------------|------|------|--------|
| **活动/事件** | 个人复盘 | 团队复盘 | 团队复盘 |
| **项目** | 个人复盘 | 项目复盘 | 项目复盘 |
| **经营/战略** | NA | NA | **战略复盘** |

**四种复盘类型**

| 类型 | 适用规模 | 适用对象 |
|------|----------|----------|
| **个人复盘** | 个人 | 活动/事件、项目 |
| **团队复盘** | 团队、跨部门 | 活动/事件 |
| **项目复盘** | 团队、跨部门 | 项目 |
| **战略复盘** | 跨部门 | 经营/战略 |

**易考点**

- 个人 + 经营/战略 = **NA**（不适用）
- 团队 + 经营/战略 = **NA**
- **战略复盘** 仅在**跨部门 + 经营/战略**场景
- 团队/跨部门 + 活动/事件 → **团队复盘**
- 团队/跨部门 + 项目 → **项目复盘**

### 1.5 正式复盘与非正式复盘

**流程对比**

| 步骤 | 正式复盘（蓝） | 非正式复盘（橙） |
|------|----------------|------------------|
| 1 | **回顾预期目标** | ❌ 跳过 |
| 2 | **回顾过程 / 评估结果** | **评估结果**（不强调回顾过程） |
| 3 | 根因分析 / 关键成功要素 | 根因分析 / 关键成功要素 |
| 4 | 经验教训 / 改进计划 | 经验教训 / 改进计划 |

**相同点**

- 后两步一致：**根因分析/关键成功要素** + **经验教训/改进计划**

**不同点**

| 对比项 | 正式复盘 | 非正式复盘 |
|--------|----------|------------|
| **回顾目标** | ✅ 有 | ❌ 无 |
| **回顾过程** | ✅ 有 | ❌ 无（只评估结果） |
| 流程 | 完整四步 | 精简（省目标、省过程回顾） |

**易考点**

- 非正式复盘**省略**：回顾预期目标、回顾过程
- 两者**共有**：根因分析 + 经验教训/改进计划
- 正式复盘更**完整严谨**；非正式复盘更**轻量**

## 二、复盘有什么价值（五大价值）

> 本章目录：复盘与 3721 原则 → 为什么要复盘（五大价值）→ 复盘的价值。

### 2.1 复盘与 3721 原则

**提升能力的 "7-2-1" 原则**

| 来源 | 占比 | 说明 |
|------|------|------|
| **工作** | **70%** | 经验来自工作实践 |
| **向他人学习** | **20%** | 从其他人身上学习 |
| **正规学习** | **10%** | 课堂/培训等正规学习 |

**图示三场景（课件）**

| 场景 | 占比 | 内容 |
|------|------|------|
| 课堂培训 | 10% | 正规学习（如管理能力培训） |
| 向他人学习 | 20% | 观察、交流、协作 |
| 工作实践 | 70% | 边工作、边学习、边总结、边应用 |

**行动口号（课件）**

> **边工作 边学习 边总结 边应用**

**易考点**

- 7-2-1 = **70% 工作 + 20% 向他人学 + 10% 正规学习**
- **工作实践**是能力提升最主要来源（70%）
- 复盘属于**工作总结**环节，对应 70% 中的"边总结"

### 2.2 为什么要复盘（五大价值）

**四象限（课件图示）**

| 象限 | 内容 |
|------|------|
| 左上（蓝） | **知其然，知其所以然** |
| 右上（深绿） | **不再犯同样的错误** |
| 左下（亮绿） | **总结规律，固化流程** |
| 右下（橙） | **传承经验，提升能力** |

**总结语（红色横幅）**

> **把失败转化为财富，把成功转化为能力**

**五大价值完整列表**

1. 知其然，知其所以然
2. 传承经验，提升能力
3. 不再犯同样的错误
4. 总结规律，固化流程
5. 知识管理中心（经验与教训）

**价值 1 详解：知其然，知其所以然 — 2×2 矩阵**

> 横轴：**绩效**（差 → 好）；纵轴：**学习效果**（差 → 好）

| | 绩效差 | 绩效好 |
|---|--------|--------|
| **学习效果好** | **有意义的失败** | **期望的成功** |
| **学习效果差** | **彻底失败** | **无意义的成功** |

**四象限解读**

| 象限 | 含义 |
|------|------|
| **期望的成功**（绩效好+学习好） | 理想状态：成功且知其所以然，可复制 |
| **有意义的失败**（绩效差+学习好） | 失败但有学习，可为未来成功铺路 |
| **无意义的成功**（绩效好+学习差） | 靠运气成功，不知原因，难复制 |
| **彻底失败**（绩效差+学习差） | 失败且无学习 |

**总结语（红色横幅）**

> 区分"**有意义的失败**"与"**无意义的成功**"

**易考点**

- 复盘目标：向"**期望的成功**"靠拢
- 关键区分：**有意义的失败** vs **无意义的成功**
- 学习效果是纵轴；绩效是横轴（勿混淆）

**价值 2 详解：传承经验，提升能力 — 经验增长曲线**

> 坐标轴：横轴 **时间**，纵轴 **经验**

| 曲线 | 形态 | 含义 |
|------|------|------|
| **期望的状况**（绿色虚线） | **阶梯式上升** | 经验**累积**，每个新阶段从上一阶段结束处继续 |
| **当前的状况**（绿色实线弧） | **周期性归零** | 经验获得但未传递，每次项目/个人都**从零开始** |

**总结语（红色横幅）**

> 如果经验不能有效传递，每个项目，每个人都接近于"**从零开始**"

**易考点**

- 复盘 = 让经验**累积传递**，避免"从零开始"
- 期望：**阶梯式**增长；当前：**周期性归零**
- 与价值1矩阵呼应：有意义的失败/成功都要**沉淀为可传递经验**

**价值 3 详解：不再犯同样的错误 — 循环流程**

```
        纠正错误（蓝）
         ↑        ↓
   分享教训（橙）← 吸取教训（绿）
```

| 步骤 | 颜色 | 含义 |
|------|------|------|
| **纠正错误** | 蓝 | 发现并修正错误 |
| **吸取教训** | 绿 | 从错误中学习 |
| **分享教训** | 橙 | 将教训分享给团队，避免重复 |

**循环关系**：纠正错误 → 吸取教训 → 分享教训 → 纠正错误（闭环）

**总结语（红色横幅）**

> 不宽容失败的组织，将会失去创新和活力，走向僵化。宁肯不干，不可做错

**易考点**

- 三步循环：**纠正 → 吸取 → 分享**（闭环防重犯）
- 文化层面：组织需**宽容失败**以保持创新活力
- "宁肯不干，不可做错" 是需警惕的僵化心态

**价值 4 详解：总结规律，固化流程 — 制度决策流程**

```
是否有制度？
  ├─ 是 → 遵照执行 → 结果是否理想？
  │                       ├─ 是 → 结束
  │                       └─ 否 → 想办法先做起来
  └─ 否 → 想办法先做起来 → 想办法先做起来 → 制定/修订
```

**流程解读**

| 决策/动作 | 含义 |
|-----------|------|
| **是否有制度？** | 判断现有流程/规范是否存在 |
| **遵照执行** | 有制度则按制度执行 |
| **结果是否理想？** | 执行后评估效果 |
| **想办法先做起来** | 无制度或效果不佳时，先实践 |
| **制定/修订** | 实践成熟后，固化/修订制度 |

**易考点**

- 有制度 → **遵照执行** → 理想则**结束**，不理想则**先做起来**
- 无制度 → **先做起来** → 成熟后**制定/修订**
- 核心思想：**先实践后固化**，避免空想制度

**价值 5 详解：知识管理中心（经验与教训）— 案例闭环**

**案例：知识管理启智培训复盘**

| 分析（问题） | 建议（改进） |
|--------------|--------------|
| 专业内容太多且难理解 | 删减不好理解的内容 |
| 对迟到行为没有惩罚 | 增加迟到挑战内容 |
| 20:30 是开始疲劳的时间点 | 精简内容，20:30 开始学员分享 |
| 领导在场，影响其他学员表达 | 副总及以上领导单独成组 |

**实施时间线（建议落地到后续场次）**

```
2班复盘 → 产品研发中心专场复盘 → 3班复盘 → 5班复盘 → ……
```

**闭环逻辑（PDCA 式）**

```
分析（问题）→ 建议（改进）→ 后续场次实施 → 持续优化
```

**易考点**

- 知识管理中心 = **经验与教训**的沉淀与复用
- 案例体现：**分析 → 建议 → 落地到后续场次**的闭环
- 与价值2（传承经验）呼应：经验需**沉淀并传递**到后续项目

### 2.3 复盘的价值

**三个维度的价值（课件）**

| 维度 | 颜色 | 价值 |
|------|------|------|
| **个人** | 蓝 | 从经验中学习，**快速提升能力** |
| **团队** | 红 | 经验**分享与传承** |
| **组织** | 绿 | 知识**萃取与共享**，组织发展与**持续改善** |

**易考点**

- 复盘价值分**三层**：个人 → 团队 → 组织
- 个人：**学习 + 提升能力**
- 团队：**分享 + 传承**
- 组织：**知识萃取 + 共享 + 持续改善**
- 与 1.2（提升组织智慧）、2.2 五大价值形成完整闭环

## 三、复盘成功心法（五心五求）

> 本章目录：复盘成功公式 → 五心五求（待截图补充）。

### 3.1 复盘成功公式

**成功公式（课件图示）**

```
洞察力            说服力              个人影响力        企业竞争力
  │                 │                   │                 │
  ↓                 ↓                   ↓                 ↓
得到复盘结论    复盘得到支持          职场上的成功      市场上的成功
```

**公式拆解**

| 能力（蓝） | 产出（黄） | 层级 |
|-----------|-----------|------|
| **洞察力** | 得到复盘结论 | 输入能力 |
| **说服力** | 复盘得到支持 | 输入能力 |
| **个人影响力** | 职场上的成功 | 输出结果 |
| **企业竞争力** | 市场上的成功 | 输出结果 |

**公式表达**

> **（洞察力 + 说服力）= （个人影响力 + 企业竞争力）**

- 左侧两项是**复盘所需能力**：洞察力得出结论，说服力让结论获得支持
- 右侧两项是**复盘带来的成功**：个人在职场成功，企业在市场成功

**"把式论"（红色横幅）**

| 类型 | 能说？ | 会干？ | 评价 |
|------|-------|--------|------|
| **真把式** | ✅ 能说 | ✅ 会干 | 真本事 |
| **假把式** | ✅ 能说 | ❌ 不会干 | 花架子 |
| **傻把式** | ❌ 不会说 | ✅ 会干 | 干了白干 |

**口诀**

> 能说会干，是**真把式**；能说不会干，是**假把式**；能干不会说，是**傻把式**。

**易考点**

- 成功公式两能力：**洞察力 + 说服力**
- 洞察力 → **得到复盘结论**；说服力 → **复盘得到支持**
- 两能力推导两成功：**个人影响力 → 职场成功**；**企业竞争力 → 市场成功**
- "把式论"三种人：**真把式**（能说会干）/ **假把式**（能说不会干）/ **傻把式**（能干不会说）
- 复盘既要有**洞察**（会干），也要有**说服**（能说），缺一不可——避免"傻把式"

### 3.2 五心（态度：五个"心"）

**五个"心"环形图（课件）**

```
            开放心态（红）
          ╱              ╲
集思广益（橙）        坦诚表达（绿）
          ╲              ╱
   反思自我（青）  ——  实事求是（紫）
```

**五心清单**

| # | 心 | 颜色 | 含义 |
|---|----|------|------|
| 1 | **开放心态** | 红 | 接纳不同观点，不固守己见 |
| 2 | **坦诚表达** | 绿 | 真实、直接地表达想法 |
| 3 | **实事求是** | 紫 | 客观求真，不夸大不掩饰 |
| 4 | **反思自我** | 青 | 从自身找原因，自我审视 |
| 5 | **集思广益** | 橙 | 汇集团队智慧，博采众长 |

**速记口诀**

> 开放、坦诚、求是、反思、集思

**易考点**

- 五心属于**态度**层面（"态度：五个'心'"）
- 五心 = **开放心态 + 坦诚表达 + 实事求是 + 反思自我 + 集思广益**
- 关键区分：
  - **开放心态**：接纳观点（对外）
  - **反思自我**：审视自身（对内）
  - **坦诚表达**：说出来（表达）
  - **实事求是**：说真话（求真）
  - **集思广益**：听大家（汇聚）
- 五心是复盘**态度/心智**基础，与 3.1 成功公式中的"洞察力+说服力"相呼应

### 3.3 五求（目的：五个"求"）

**五求对照表（不是 → 而是）**

| # | ❌ 不是—— | ✅ 而是—— | 求 |
|---|----------|-----------|-----|
| 1 | 自己骗自己，证明自己对 | 重在**实事求是** | **求真** |
| 2 | 流于形式，走过场 | 重在**内容和找原因** | **求实** |
| 3 | 追究责任，开批判会 | 重在**改进和提高** | **求学** |
| 4 | 强调客观，推卸责任 | 重在**反思和自我剖析** | **求内** |
| 5 | 简单下结论，刻舟求剑 | 重在**找到本质和规律** | **求道** |

**五求环形图（课件）**

```
            真（红）
          ╱        ╲
   道（橙）        实（绿）
          ╲        ╱
            学（紫）——内（青）
```

**五求清单**

| # | 求 | 颜色 | 核心要义 |
|---|----|------|---------|
| 1 | **求真** | 红 | 实事求是，不骗自己 |
| 2 | **求实** | 绿 | 重内容、找原因，不走过场 |
| 3 | **求学** | 紫 | 重改进提高，不追究责任 |
| 4 | **求内** | 青 | 重反思自我剖析，不推卸责任 |
| 5 | **求道** | 橙 | 找本质规律，不简单下结论 |

**速记口诀**

> 真、实、学、内、道

**易考点**

- 五求属于**目的**层面（"目的：五个'求'"）
- 五求 = **求真 + 求实 + 求学 + 求内 + 求道**
- "不是/而是"对照是高频考点：
  - 求真：不是"自己骗自己证明自己对"，而是"实事求是"
  - 求实：不是"流于形式走过场"，而是"重内容和找原因"
  - 求学：不是"追究责任开批判会"，而是"重改进和提高"
  - 求内：不是"强调客观推卸责任"，而是"重反思和自我剖析"
  - 求道：不是"简单下结论刻舟求剑"，而是"找本质和规律"
- 与 3.2 五心呼应：**五心是态度，五求是目的**，共同构成复盘成功心法

## 四、如何开展复盘（流程工具）

> 本章目录（Part 4）：复盘前期筹备 → 复盘现场引导 → 复盘后续行动 → 案例：产品项目全流程复盘。

### 4.1 复盘前期筹备

**步骤 1：确定复盘的主题、范围、参加人**

| # | 要素 | 颜色 | 要点 |
|---|------|------|------|
| 01 | **主题** | 深绿 | 选择一个事件、活动进行复盘（**新的事、重要的事、有价值的事、未达预期的事**） |
| 02 | **范围** | 蓝 | 追求**最大程度的参与**，所有参与行动的人都要出席，都有**同样的发言权** |
| 03 | **参加人** | 红 | 由**团队自行组织**，最好不要有"领导"或"专家"指手画脚、居高临下 |

**三要素解读**

| 要素 | 核心关键词 | 说明 |
|------|-----------|------|
| **主题** | 选什么事 | 新/重要/有价值/未达预期 的事件才值得复盘 |
| **范围** | 谁来参与 | 全员参与、平等发言权，不遗漏行动参与者 |
| **参加人** | 如何组织 | 团队自组织，避免领导/专家压制发言 |

**易考点**

- 前期筹备三要素 = **主题 + 范围 + 参加人**
- 主题选择标准：**新的事、重要的事、有价值的事、未达预期的事**
- 范围原则：**最大程度参与** + **同等发言权**（人人平等）
- 参加人原则：**团队自行组织**，避免"领导/专家"指手画脚、居高临下
- 易错点：范围 ≠ 只请核心成员，而是**所有参与行动的人**都要出席

**步骤 2：确定复盘会议的时间、地点**

| 要素 | 颜色 | 要点 |
|------|------|------|
| **时间** | 深绿 | ① 行动过程中或结束之后**尽快进行**；② 时长控制在 **15 分钟～1 小时** |
| **地点** | 深红 | **便利为主**，离**任务执行地越近越好** |

**易考点**

- 前期筹备步骤 2 = **时间 + 地点**
- 时间两要点：**尽快进行**（过程中或结束后）+ **时长 15 分钟～1 小时**
- 地点原则：**便利为主**，**靠近任务执行地**
- 易错点：复盘不是"事后很久才开"，而是**尽快**；时长有上限（≤1 小时），避免拖沓

**步骤 3：收集复盘材料**

| # | 类别 | 颜色 | 内容 |
|---|------|------|------|
| 01 | **通知** | 深绿 | 启动通知、启动会、发文等 |
| 02 | **数据** | 蓝 | 计划方案、KPI 指标及统计结果等 |
| 03 | **报告** | 深红 | 执行过程中产生的工作总结文档、报告等 |

**易考点**

- 前期筹备步骤 3 = 收集**三类复盘材料**：通知 + 数据 + 报告
- **通知类**：启动通知、启动会、发文（启动阶段材料）
- **数据类**：计划方案 + KPI 指标及统计结果（既含计划也含结果）
- **报告类**：执行过程中产生的工作总结文档、报告（过程记录）
- 易错点：数据类**不仅含结果**（KPI），还含**计划方案**；报告类侧重**执行过程**中的总结

### 4.2 复盘现场引导

> 现场引导按阶段推进：开场 → （后续阶段待截图补充）。

**阶段 1：开场（1-开场）**

开场四步流程（课件图示，沿时间轴从左到右）：

| 步骤 | 内容 | 颜色 |
|------|------|------|
| 1 | **强调复盘目的** | 蓝 |
| 2 | **介绍复盘的规则** | 红 |
| 3 | **介绍复盘流程** | 绿 |
| 4 | **介绍复盘事件** | 紫 |

**四步解读**

| 步骤 | 关键词 | 说明 |
|------|--------|------|
| 强调复盘目的 | 目的 | 让参与者明确"为什么复盘" |
| 介绍复盘的规则 | 规则 | 明确发言权、坦诚、对事不对人等规则 |
| 介绍复盘流程 | 流程 | 说明复盘将按什么步骤进行 |
| 介绍复盘事件 | 事件 | 交代要复盘的具体事件/活动背景 |

**速记口诀**

> 目的 → 规则 → 流程 → 事件

**易考点**

- 现场引导开场 = **四步**：强调目的 / 介绍规则 / 介绍流程 / 介绍事件
- 顺序：先**目的**（为什么）→ **规则**（怎么发言）→ **流程**（怎么进行）→ **事件**（复盘什么）
- 易错点：开场**先讲目的**而非先讲事件；规则与流程不同（规则=发言规范，流程=步骤顺序）

**阶段 2：复盘规则（2-复盘规则）**

**六条复盘规则（规则）**

| # | 规则 | 关键词 |
|---|------|--------|
| 1 | **开放，平等，坦诚表达** | 开放/平等/坦诚 |
| 2 | **聆听 & 探询，欣赏并包容与你不同的看法** | 聆听/包容异见 |
| 3 | **多反思自我** | 反思自我 |
| 4 | **实事求是，对事不对人** | 求真/对事不对人 |
| 5 | **畅所欲言，集思广益，不一言堂** | 畅言/集思/反一言堂 |
| 6 | **以学习为导向，不批评，不表扬，不"秋后算账"** | 学习导向/三不 |

**引导者建议（建议）**

> 将复盘规则**写到大白纸上**，张贴到会场**醒目的地方**，提醒与会者。

**易考点**

- 复盘规则共**六条**：开放平等坦诚 / 聆听包容异见 / 多反思自我 / 实事求是对事不对人 / 畅言集思反一言堂 / 学习导向三不
- 第六条"三不" = **不批评、不表扬、不"秋后算账"**（高频考点）
- "对事不对人" + "不一言堂" + "学习导向" 是核心精神
- 引导者落地动作：规则**写大白纸 + 张贴醒目处**，持续提醒
- 与 3.2 五心呼应：开放心态/坦诚表达/反思自我/集思广益/实事求是 均在规则中体现

**现场引导四步主流程（课件顶部流程）**

```
回顾目标 → 评估结果 → 差异分析 → 总结经验
 (3)        (4)        (5)        (6)
```

> 阶段 3~6 为现场引导的主体四步，对应正式复盘四步流程。

**阶段 3：回顾目标（3-回顾目标）**

| 维度 | 内容 |
|------|------|
| **输出物-目的** | 事件、活动所需达到的**效果** |
| **输出物-目标** | 遵循 **SMART 原则**，形成**共识** |

**目的与目标的区别（课件重点）**

| 项 | 颜色 | 箭头 | 定义 |
|----|------|------|------|
| **目的** | 浅蓝 | ↑ 向上 | 事情、事件、活动、目标达成的**效果**（总体"为什么"） |
| **目标** | 紫 | ↓ 向下 | 在**某一阶段**达成的**某一成果**，遵 **SMART 原则**（阶段性成果） |

**对比要点**

- **目的**：偏总体/方向，回答"**为什么做**"，是达成的**效果**
- **目标**：偏阶段/具体，回答"**做到什么**"，须 **SMART** 且是**某一阶段的某一成果**
- 目的可对应多个阶段目标；目标是目的在具体阶段的落地

**SMART 原则（目标制定/回顾标准）**

| # | 字母 | 原则 | 颜色 | 含义 |
|---|------|------|------|------|
| 01 | S | **具体的** Specific | 绿 | 切中**特定的工作指标**，不能笼统 |
| 02 | M | **可衡量的** Measurable | 蓝绿 | 有具体**衡量目标是否完成**的评价标准 |
| 03 | A | **可达到的** Attainable | 红 | 付出努力**可以实现**，避免过高或过低 |
| 04 | R | **相关的** Relevant | 浅绿 | 与**其它目标相关联**；绩效指标与本职工作相关 |
| 05 | T | **有时限的** Time-bound | 蓝 | 有**时间/事件限制** |

**速记口诀**

> S 具体、M 可衡量、A 可达到、R 相关、T 有时限

**易考点**

- SMART 五要素 = **Specific / Measurable / Attainable / Relevant / Time-bound**
- 中文：**具体的 / 可衡量的 / 可达到的 / 相关的 / 有时限的**
- S=切中特定指标不笼统；M=有衡量标准；A=努力可实现（避免过高/过低）；R=与其它目标及本职相关；T=有时限
- 易错点：A 是"可达到"（非"有野心"）；R 是"相关"（非"现实"）；T 是"有时限"（非"可追踪"）

**案例：模糊目标 → SMART 目标（3 个对照）**

| # | ❌ 模糊/不切实际（左） | ✅ 具体/SMART（右） | 体现原则 |
|---|----------------------|---------------------|---------|
| 01 | 增强客户意识 | **12 月 31 日前**，通过优化对客服务流程**减少客诉率 2%** | S/M/T（具体+可衡量+有时限） |
| 02 | 组织所有员工进行管理培训 | **6 月 31 日前**组织一场**时间管理培训**，效果评估得分**不低于 85 分** | S/M/T（具体+可衡量+有时限） |
| 03 | xx 员工（初中毕业）**半年内**取得**专业英语八级**证书 | xx 员工（初中毕业）**一个月内**掌握 **10 句常用口语** | A（可达到：避免过高目标） |

**案例解读**

- 案例 01、02：从**笼统口号** → **带时限 + 可衡量指标**的具体目标
- 案例 03：从**不切实际的高目标**（初中毕业半年拿专八）→ **可达成的合理目标**（一月掌握 10 句口语），体现 **A 可达到**
- 三案例共同体现：目标要**具体、可衡量、有时限、可达到**

**常用问题（引导提问）**

1. 当初行动的**意图或目的**是什么？
2. 事件/行动想要达到的**目标**是什么？
3. 预先制定的**计划**是什么？（计划的每一个节点即是**小目标**）

**难点（黑底高亮）**

| # | 难点 |
|---|------|
| 1 | **没有目标** |
| 2 | **目标不清** |
| 3 | **缺乏共识** |
| 4 | 目标没有**分解**或者**可行性** |
| 5 | 与**计划脱节** |

**易考点**

- 现场引导主体四步 = **回顾目标 → 评估结果 → 差异分析 → 总结经验**
- 回顾目标输出物：**目的**（效果）+ **目标**（SMART 原则 + 共识）
- 目标须遵循 **SMART 原则**并形成**共识**（高频考点）
- 常用三问：意图/目的？目标？计划（节点=小目标）？
- 五大难点：没有目标 / 目标不清 / 缺乏共识 / 未分解或不可行 / 与计划脱节
- 易错点：目的 ≠ 目标（目的是总体"效果/为什么"，目标是阶段"成果/做到什么"+ SMART）；计划节点 = 小目标

**阶段 4：评估结果（4-评估结果）**

| 维度 | 内容 |
|------|------|
| **输出物-亮点** | 哪些**达到甚至超出**了预期？ |
| **输出物-不足** | 哪些**未达到**预期？ |

**常用问题（引导提问）**

1. **实际过程**是什么？（做了什么，发生了什么？）
2. 实际结果与预期目标相比，有哪些**亮点**，哪些**不足**？

**难点（黑底高亮）**

| # | 难点 | 含义 |
|---|------|------|
| 1 | **报喜不报忧** | 只说成绩，隐瞒问题 |
| 2 | **流水账，纠缠于细节** | 事无巨细罗列，陷入细节 |
| 3 | **罗生门** | 各执一词，事件版本冲突 |
| 4 | **盲人摸象** | 只见局部，不见整体 |
| 5 | **跳跃难点** | 跳过难点，回避关键问题 |

**易考点**

- 评估结果输出物 = **亮点**（达到/超预期）+ **不足**（未达预期）
- 常用两问：实际过程？实际结果 vs 预期目标的亮点/不足？
- 五大难点：**报喜不报忧 / 流水账纠缠细节 / 罗生门 / 盲人摸象 / 跳跃难点**
- 与回顾目标呼应：评估结果 = 把"实际结果"与"回顾的目标"做**亮点/不足**对比
- 易错点：评估结果重在**对比预期**（非单纯罗列结果）；难点"罗生门/盲人摸象"强调**视角片面**，需全景还原

**复盘的两大流派（评估结果的方法论）**

| 维度 | 过程还原派 | 绩效导向派 |
|------|-----------|-----------|
| **代表** | 美军、英国石油公司（BP） | 联想、谷歌 |
| **做法** | 按**时间顺序或职能条线**，把主要时间、关键环节**复现**一遍，找出待深入探究的**关键事件** | **对照目标**，列出哪些做得好/不好/有改进空间；第三阶段分析根因时如有必要再复现过程 |
| **优点** | 操作简便符合习惯，事实线索清晰，易于理清思路；对不了解全部过程的人**本身就是学习**，有助于就事实过程**达成共识** | 简单、直接、高效，**以结果为导向**，对照目标，保持**聚焦**，避免陷入细节或平铺直叙 |
| **缺点** | 可能陷入"**流水账**"或纠缠技术细节，**时间冗长**；了解全局的成员感到重复或没必要 | 部分成员对事实过程**缺乏了解或未有共识**，难以参与讨论，影响团队**相互了解** |

**两派对比要点**

| 对比项 | 过程还原派 | 绩效导向派 |
|--------|-----------|-----------|
| 切入方式 | 按**时间/职能**复现过程 | **对照目标**看结果 |
| 导向 | 过程/事实导向 | **结果导向** |
| 风险 | 流水账、冗长 | 缺共识、难参与 |
| 适合 | 不熟悉全过程的团队 | 需聚焦高效的复盘 |

**易考点**

- 复盘两大流派 = **过程还原派**（美军/BP）+ **绩效导向派**（联想/谷歌）
- 过程还原派：按**时间/职能复现**，优点是**达成共识**，缺点是**流水账/冗长**
- 绩效导向派：**对照目标**看结果，优点是**聚焦高效**，缺点是**缺共识/难参与**
- 代表企业对应（高频）：过程还原派→**美军、BP**；绩效导向派→**联想、谷歌**
- 易错点：两派不是对立好坏，而是**切入方式不同**（过程 vs 结果）；绩效导向派在第三阶段分析根因时**仍可复现过程**

**评估结果注意事项：讲事实，不讲观点**

**"结果"的定义**

> 做了什么事，产生了什么结果，反映事情的**最终状态**

**核心原则**

> **讲事实，不讲观点**

**对比示例**

| 类别 | 描述 | 示例 |
|------|------|------|
| ❌ **讲观点**（主观） | 模糊主观评价 | "会议纪律差"、"计划性不足" |
| ✅ **讲事实**（客观） | 客观描述 + 数据支撑 | "会议中 20% 的人玩手机，10 人未到，5 人迟到"；"停机检修前未制定详细的检修计划表" |

**易考点**

- 评估结果核心原则：**讲事实，不讲观点**
- "结果"= 做了什么事 + 产生什么结果 + 反映**最终状态**
- 观点 vs 事实区分（高频）：
  - 观点："会议纪律差" → 事实："20% 玩手机、10 人未到、5 人迟到"
  - 观点："计划性不足" → 事实："未制定详细的检修计划表"
- 事实 = **客观描述 + 数据/行为支撑**；观点 = 模糊主观评价
- 与 4.2 阶段 2 复盘规则呼应：**实事求是、对事不对人**

**阶段 5：差异分析（5-差异分析）**

| 维度 | 内容 |
|------|------|
| **输出物 1** | **成功的关键因素** |
| **输出物 2** | **失败的根本原因** |

**常用问题（引导提问）**

1. **真正起作用的关键因素**是什么？
2. **失败的根本原因**是什么？
3. 哪些**主客观因素**造成我们未达预期目标？

**难点（黑底高亮）**

| # | 难点 | 含义 |
|---|------|------|
| 1 | **浅尝辄止** | 分析停留在表面，未深挖根因 |
| 2 | **线性思考** | 单一归因，忽略多因素交互 |
| 3 | **争吵或冲突** | 观点对立引发争执，偏离分析 |
| 4 | **归罪于外** | 推卸责任，归咎外部/他人 |
| 5 | **面面俱到 → 拖沓冗长** | 试图覆盖所有点，导致冗长低效 |

**易考点**

- 差异分析输出物 = **成功的关键因素** + **失败的根本原因**
- 常用三问：关键因素？根本原因？主客观因素？
- 五大难点：**浅尝辄止 / 线性思考 / 争吵或冲突 / 归罪于外 / 面面俱到→拖沓冗长**
- 与 3.3 五求呼应：**求实**（找原因）、**求内**（反思自我不归罪于外）、**求道**（找本质规律不浅尝辄止）
- 与阶段 3、4 衔接：差异分析 = 在"回顾目标 + 评估结果"基础上，分析**亮点/不足背后的根因**
- 易错点：差异分析重在**根因**（非表面原因）；"归罪于外"违背求内精神

**原因分析方法：5why（冰山模型）**

**冰山模型（左：现在 vs 过去）**

```
═══════ 水线 ═══════   ← 现在（水面以上）
  现象 (WHY) → 察觉(异常点) → 问题 → 灌急处理
─────────────────────  ← 过去（水面以下）= 改善行动
  一次因/近因 (真因①) → 治标对策(暂时)
       ↓ WHY
  真因② …
       ↓ WHY
  N次因/远因 (真因ⁿ) → 治本对策(永久)
```

**原因层级（右：由表及里）**

| 层级 | 原因 | 颜色 | 对应对策 |
|------|------|------|---------|
| 1 | **问题表象**（症状） | 黄 | 紧急处理 |
| 2 | **直接原因** | 浅橙 | — |
| 3 | **中间原因** | 深橙 | — |
| 4 | **根本原因** | 红 | 治本对策（永久） |

**5why 核心逻辑**

| 分析深度 | 因果层级 | 对策类型 |
|---------|---------|---------|
| 表面（水面以上） | 现象/问题 | **紧急处理**（治标不治本） |
| 近因（一次因） | 直接原因 | **治标对策**（暂时） |
| 远因（N 次因） | 根本原因 | **治本对策**（永久） |

**易考点**

- 5why 用于**差异分析**阶段，深挖**根本原因**
- 冰山模型：水面以上 = **现在/现象**（紧急处理）；水面以下 = **过去/真因**（改善行动）
- 三种对策对应三层：现象→**紧急处理**；近因→**治标对策（暂时）**；远因/根因→**治本对策（永久）**
- 原因层级四步：**问题表象 → 直接原因 → 中间原因 → 根本原因**
- 水面以下（近因之后）整体属于**改善行动**
- 与 3.3 五求呼应：**求实**（找原因）、**求道**（找本质规律，不止于近因）
- 易错点：5why 不是问 5 次"为什么"就停，而是**追到根因**；近因对策是**治标**，远因对策才是**治本**

**5why 定义与要点**

> 通过**不断提问**为什么前一个事件会发生，直到回答"**没有更深入的原因**"或直到一个**新的问题被发现**时才停止提问。

> ⚠️ **注意：5 个为什么 ≠ 问 5 次为什么**（重在**深度**，非固定次数）

**经典案例：机器突然停止的根本原因**

| 层级 | 问（为什么） | 答（真因） |
|------|------------|-----------|
| Q1 | 为什么机器停了？ | 因为**超过了负荷**，保险丝断了 |
| Q2 | 为什么超负荷？ | 因为**轴承的润滑不够** |
| Q3 | 为什么润滑不够？ | 因为**润滑泵吸不上油来** |
| Q4 | 为什么吸不上油来？ | 因为**油泵轴磨损、松动**了 |
| Q5 | 为什么磨损了？ | 因为**没有安装过滤器**，混进铁屑等杂质 |

**结论**

> 经过连续 5 次**由表及里**不停地问"为什么"，才找到问题的**真正原因和解决方法**：在油泵轴上安装**过滤器**。

**案例逻辑链**

```
机器停止 ← 超负荷 ← 润滑不够 ← 吸不上油 ← 油泵轴磨损 ← 未装过滤器(根因)
   现象                                            直接原因     根本原因
```

**易考点**

- 5why 定义：不断问"为什么"直到"**没有更深入原因**"或"**发现新问题**"才停止
- 关键辨析（高频）：**5 个为什么 ≠ 问 5 次为什么**（重深度非次数）
- 经典案例根因 = **未安装过滤器**（混进铁屑致油泵轴磨损→吸不上油→润滑不够→超负荷→停机）
- 解决方法 = **安装过滤器**（治本对策，对应冰山模型"远因→永久对策"）
- 由表及里五层：停机 → 超负荷 → 润滑不够 → 吸不上油 → 磨损 → 未装过滤器

**原因分析方法：鱼骨图（因果图 / 石川图）**

**概念**

- 它把**原因与潜在问题或结果**联系起来
- **激发**关于问题的**思考**，并且有助于把**思想组织起来**

**作用**

- 直观地显示各种因素如何与潜在问题或结果相联系，**找出产生问题的根本原因**
- 因果图还可以用于**识别风险**

**鱼骨图五大要因（人机料法环变体）**

| 要因 | 别名 | 子项示例 |
|------|------|---------|
| **人员因素** | 人 | 技能不足、缺乏责任心、态度问题、团队凝聚力低、规划不清、缺乏培训 |
| **工具技术** | 机/技 | 选型不当、不熟悉、工具不稳定、技术不成熟、对创新技术不熟悉 |
| **资源** | 料 | 软硬件配置 |
| **方法** | 法 | 估算不准、人员安排不当、风险意识弱、变更控制、模型选择不当、流程不规范、里程碑问题、跟踪不及时 |
| **环境** | 环 | 团队氛围不稳、工作环境、企业文化、组织体制、权力政治 |

**鱼骨图结构示意**

```
人员 ──┐
工具 ──┤
        ├──→ 问题/结果（鱼头，朝右）
资源 ──┤
方法 ──┤
环境 ──┘
```

**易考点**

- 鱼骨图别名 = **因果图 / 石川图**（Ishikawa Diagram）
- 概念两要点：**联系原因与结果** + **激发思考、组织思想**
- 作用两要点：**找根本原因** + **识别风险**
- 五大要因 = **人员 / 工具技术 / 资源 / 方法 / 环境**（人机料法环的项目变体）
- 与 5why 互补：5why **纵向深挖**单条因果链；鱼骨图**横向发散**多要因，再对每条深挖
- 与 3.3 五求呼应：**求实**（找原因）、**求道**（找根本原因/规律）

**鱼骨图标准框架：5M1E（人机料法环测）**

| 维度 | 中文 | 颜色 | 子项示例 |
|------|------|------|---------|
| **Man** | 人 / 人力 | 红 | 技术水平、责任意识、管理能力 |
| **Machine** | 机 / 机械 | 蓝 | 设备功能、运行维护 |
| **Material** | 料 / 物料 | 黄/灰 | 材料供应、运输时效 |
| **Method** | 法 / 方法 | 橙/青 | 设计方法、工艺流程、管理流程 |
| **Environment** | 环 / 环境 | 绿 | 生产环境、市场环境 |
| **Measurement** | 测 / 测量 | 深蓝/灰 | 测试方法、测试标准 |

**5M1E 环形图（顺时针）**

```
        人力(人)
      ╱          ╲
  测量(测)        机械(机)
      │   5M1E    │
  环境(环)        物料(料)
      ╲          ╱
        方法(法)
```

**易考点**

- 5M1E = **人(Man) + 机(Machine) + 料(Material) + 法(Method) + 环(Environment) + 测(Measurement)**
- 中文速记：**人机料法环测**（六要因，比"人机料法环"多一个"测"）
- 各维度典型子项：
  - 人：技术水平 / 责任意识 / 管理能力
  - 机：设备功能 / 运行维护
  - 料：材料供应 / 运输时效
  - 法：设计方法 / 工艺流程 / 管理流程
  - 环：生产环境 / 市场环境
  - 测：测试方法 / 测试标准
- 易错点：5M1E 是**六个**维度（含"测"），勿漏"测量"；与项目变体（人员/工具技术/资源/方法/环境）区分——5M1E 为**通用标准**框架

**鱼骨图示例：料 / 法 维度子因素**

| 主骨（维度） | 子骨（子因素） |
|-------------|---------------|
| **料（产品）** | 产品质量、产品市场占有率、产品品牌知名度、…… |
| **法** | 工作流程、管理制度、工作方法、…… |

**示例解读**

- 每条主骨下可继续**发散子因素**（如"料"下展开产品质量/市占率/品牌知名度）
- 子因素列举后，可对每条用 **5why** 进一步深挖根因
- 虚线"……"表示**未穷尽**，需根据实际问题继续补充

**易考点**

- 鱼骨图用法：主骨（5M1E 维度）→ 子骨（具体子因素）→ 对子因素再 5why 深挖
- 示例子因素：
  - 料：产品质量 / 市场占有率 / 品牌知名度
  - 法：工作流程 / 管理制度 / 工作方法
- 鱼骨图 + 5why 组合：**横向发散（鱼骨图）+ 纵向深挖（5why）**，二者互补
- 易错点：子因素**未穷尽**（虚线省略），需结合实际问题继续补充，不可只列示例

**阶段 6：总结经验（6-总结经验）**

| 维度 | 内容 |
|------|------|
| **输出物 1** | **学到的经验教训** |
| **输出物 2** | **未来行动改善建议** |

**常用问题（引导提问）**

1. 我们能从中学到什么？即有哪些**值得坚持的做法**，有哪些**改进之处**？
2. 接下来我们要做什么（**SMART 原则**）？（**短期 vs 长期**）

**难点（黑底高亮）**

| # | 难点 | 含义 |
|---|------|------|
| 1 | **就事论事** | 停留在表面，未提炼规律 |
| 2 | **好高骛远（超出可控范围）** | 目标过高超出可控范围 |
| 3 | **过快得出结论** | 草率下结论，未充分论证 |
| 4 | **缺乏行动点** | 只有结论无落地行动 |

**易考点**

- 总结经验输出物 = **经验教训** + **未来行动改善建议**
- 常用两问：学到什么（坚持/改进）？接下来做什么（SMART + 短期/长期）？
- 行动建议须遵循 **SMART 原则**，并区分**短期 vs 长期**
- 四大难点：**就事论事 / 好高骛远 / 过快结论 / 缺乏行动点**
- 与阶段 3 回顾目标呼应：行动建议再次用 **SMART 原则**（闭环）
- 与 3.3 五求呼应：**求道**（提炼规律，不就事论事）、**求学**（重改进提高）
- 易错点：总结经验须**有行动点**（非空谈）；行动要**可控**（非好高骛远）；结论**不草率**

**四步主流程闭环（回顾）**

```
回顾目标 → 评估结果 → 差异分析 → 总结经验
  (SMART)   (亮点/不足)  (根因)    (经验+行动SMART)
```

> 总结经验的行动建议回到 SMART 原则，与回顾目标形成闭环。

**基本信息**

| 项 | 内容 |
|----|------|
| 时间 | 202x 年 xx 月 xx 日 |
| 地点 | 张三家 |
| 事项 | 张三减肥复盘 |
| 参加人 | 张三一家人 |

**复盘分析表（步骤 1~4，对应四步主流程）**

| 步骤 | 类别 | 内容 |
|------|------|------|
| **1. 我们预期发生什么？**（回顾目标） | 目的 | 张三减肥，为了身体健康 |
| | 目标 | **3 个月减肥 3 公斤** |
| **2. 实际发生了什么？**（评估结果） | 实际过程 | 每天少吃一顿饭；每天至少跑步 5 公里 |
| | 结果：亮点 | **2 个月减肥 3 公斤**，身体健康 |
| | 结果：不足 | 减肥太快，妈妈心疼 |
| **3. 造成差异的原因是什么？**（差异分析） | 成功的关键因素 | ① 每天坚持 ② 父亲每天陪跑 ③ 母亲合理安排饮食 |
| | 失败的根本原因 | 没有 |
| **4. 如何在下次改进**（总结经验） | | 坚持当前的做法继续减肥 |

**改进行动计划闭环（步骤 5）**

| 具体的改进行动 | 是否知识沉淀 | 责任人 | 计划完成时间 | 实际完成时间 | 状态 |
|---------------|------------|--------|------------|------------|------|
| 每天少吃一顿饭，跑步 5 公里 | 否 | 张三 | 202X 年 X 月 XX 日 | 202X 年 X 月 XX 日 | 完成 |

**案例逻辑映射**

```
步骤1 预期(目的+目标)        ← 回顾目标
步骤2 实际(过程+亮点+不足)    ← 评估结果
步骤3 原因(成功因素+失败根因) ← 差异分析
步骤4 改进(经验)              ← 总结经验
步骤5 行动闭环(行动+责任人+时间+状态) ← 复盘后续行动
```

**易考点**

- 案例五步 = **预期 → 实际 → 原因 → 改进 → 行动闭环**，对应四步主流程 + 后续行动
- 步骤 1 目标 = **3 个月减 3 公斤**；步骤 2 实际 = **2 个月减 3 公斤**（超预期，属亮点）
- 步骤 2 不足 = **减肥太快，妈妈心疼**（非业务失败，是副作用）
- 步骤 3 成功三因素：**每天坚持 + 父亲陪跑 + 母亲安排饮食**（团队/家庭支持）
- 步骤 5 行动闭环字段：**行动 + 是否知识沉淀 + 责任人 + 计划时间 + 实际时间 + 状态**
- 易错点：本案例"失败根本原因=没有"（因超预期成功）；"是否知识沉淀"字段用于区分**行动类**与**沉淀类**改进

**阶段 8：复盘常用方法（8-复盘常用方法）— 五步循环法**

**五步循环流程（顺时针）**

```
          ①个人准备（红，12点）
        ╱                      ╲
⑤交流成果（橙，10点）      ②组内分享（绿，2点）
        ╲                      ╱
          ④小组决策（青，7点）—③小组讨论（紫，5点）
```

**五步清单**

| 步骤 | 方法 | 颜色 | 时位 | 含义 |
|------|------|------|------|------|
| 1 | **个人准备** | 红 | 12 点 | 各人独立思考、准备发言 |
| 2 | **组内分享** | 绿 | 2 点 | 组内成员依次分享观点 |
| 3 | **小组讨论** | 紫 | 5 点 | 集体讨论、碰撞观点 |
| 4 | **小组决策** | 青 | 7 点 | 形成共识与决策 |
| 5 | **交流成果** | 橙 | 10 点 | 输出/汇报成果，闭环 |

**易考点**

- 复盘常用方法 = **五步循环法**：个人准备 → 组内分享 → 小组讨论 → 小组决策 → 交流成果
- 顺序（顺时针）：**个人准备（红）→ 组内分享（绿）→ 小组讨论（紫）→ 小组决策（青）→ 交流成果（橙）**
- 流程特点：**先个人后集体**（个人准备→组内→小组），**先讨论后决策**（讨论→决策），**闭环输出**（交流成果）
- 与 4.2 阶段 2 复盘规则呼应：**畅所欲言、集思广益、不一言堂**（个人准备保证人人发言，避免一言堂）
- 易错点：顺序不可乱——**个人准备在最前**（避免被他人观点带偏），**交流成果在最后**（闭环输出）

### 5.1 常见问题：1-Goal 回顾目标

|------|------|------|
| 没有目标/目标不清 | SMART | 套用 SMART 五原则补全目标 |
| 目标缺乏共识 | 张贴展示 | 把目标**可视化张贴**，让全员看到、对齐 |
| 无目标分解 | 目标分解 | 把目标**拆解**到节点/小目标（呼应回顾目标"计划节点=小目标"） |

**三大应对策略（课件蓝框）**

| # | 问题 | 应对策略 |
|---|------|---------|
| 1 | **目标不清** | **SMART** 原则 |
| 2 | **缺乏分解** | **WBS**（工作分解结构） |
| 3 | **缺乏行动计划** | **进度计划表** |

**易考点**

- 回顾目标三大常见问题 = **没有目标/目标不清 + 目标缺乏共识 + 无目标分解**
- 对应对策：**SMART + 张贴展示 + 目标分解**
- 课件蓝框三大策略：目标不清→**SMART**；缺乏分解→**WBS**；缺乏行动计划→**进度计划表**
- 与 4.2 阶段 3 回顾目标呼应：
  - "没有目标/目标不清" → 用 **SMART**（阶段 3 已学）
  - "缺乏共识" → **张贴展示**（与阶段 2 复盘规则"规则写大白纸张贴"同理）
  - "无目标分解" → **目标分解 / WBS**（呼应"计划节点=小目标"）
- 易错点：⚠️ 标记的"没有目标或目标不清"是**首要问题**，对策是 **SMART**（非"重新定目标"）；"分解"对策为 **WBS**（工作分解结构）

- 评估结果四大常见问题 = **报喜不报忧 + 报流水账/纠缠细节 + 盲人摸象/罗生门 + 跳跃到经验教训**
- 课件蓝框五大策略：

  - 盲人摸象 → **相关利益者均需到场**（全景视角）

  - 思维跳跃 → 遵循**顺序和步骤**（不跳到经验教训）
- 与 4.2 阶段 4 评估结果难点呼应：报喜不报忧 / 流水账 / 罗生门 / 盲人摸象 / 跳跃难点

### 5.3 常见问题：3-Analysis 分析原因

**分析原因阶段六大常见问题与对策**

| # | 常见问题 | 应对策略/工具 |
|---|---------|-------------|
| 1 | **浮于表面** ⚠️ | **5why / 鱼骨图 / 问题罗盘** |
| 2 | **一团乱麻** | **名义小组**（名义小组法） |
| 3 | **本位主义** | **引导师**（引导师引导） |
| 4 | **归罪于外，相互指责** ⚠️ | **领导人以身作则** |
| 5 | **面面俱到，拖沓冗长** | 聚焦关键，控制时长 |
| 6 | **只盯失败或不足，批斗会** | **引导师**（引导师纠偏） |

**四大常见误区应对策略（课件蓝框）**

| # | 误区 | 应对策略 |
|---|------|---------|
| 1 | **快速得出结论** | **重视成果普适性** |
| 2 | **超出可控范围** | **关注能掌控的事情** |
| 3 | **无后续行动** | **制定清晰后续计划** |
| 4 | **止于就事论事** | **通过现象看本质** |

**易考点**

- 分析原因六大问题 = **浮于表面 + 一团乱麻 + 本位主义 + 归罪于外相互指责 + 面面俱到拖沓 + 只盯失败批斗会**
- 工具/角色对策：
  - 浮于表面 → **5why / 鱼骨图 / 问题罗盘**（深挖根因工具）
  - 一团乱麻 → **名义小组**（结构化讨论）
  - 本位主义 / 批斗会 → **引导师**（引导纠偏）
  - 归罪于外 → **领导人以身作则**
- 四大误区对策（高频）：
  - 快速得出结论 → **重视成果普适性**
  - 超出可控范围 → **关注能掌控的事情**
  - 无后续行动 → **制定清晰后续计划**
  - 止于就事论事 → **通过现象看本质**
- 与 4.2 阶段 5 差异分析难点呼应：浅尝辄止(浮于表面) / 线性思考 / 争吵或冲突(相互指责) / 归罪于外 / 面面俱到拖沓
- 与 3.3 五求呼应：**求道**（通过现象看本质，不止于就事论事）、**求内**（不归罪于外）
- 易错点：⚠️ "浮于表面"和"归罪于外"是两大重点问题；"止于就事论事"对策是**通过现象看本质**（非"深挖根因"口号）
