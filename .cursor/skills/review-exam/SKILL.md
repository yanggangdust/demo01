## 一、什么是复盘（原理类型）

> 本章目录：复盘定义 → 目的 → 适用事件 → 类型 → 正式/非正式 → 与工作总结区别 → 七大特点。

### 1.1 什么是复盘

#### 复盘的定义与起源

- **本义**：围棋术语，指对局结束后**重演整盘棋**，研究对局过程
- **引申义**：任务完成后，**从头到尾重新梳理一遍**整个过程
- **目的**：
  - 持续**验证和纠正**目标
  - 找出**原因/理由**
  - 分析结果（**算账**）
  - 提升**认识**
  - 总结**规律/法则**

#### 美军 AAR（After Action Review）

- **定义**：围绕**绩效表现**对一次事件进行的**专业讨论**
- **核心**：帮助参与者**自己发现**发生了什么、为什么发生
- **目标**：
  - **保持优势**
  - **改正缺点**

**易考点**

| 概念 | 要点 |
|------|------|
| 复盘本义 | **围棋**术语，重演对局研究过程 |
| AAR 全称 | **After Action Review**（行动后反思） |
| AAR 核心 | 围绕**绩效表现**；参与者**自己发现** |
| AAR 目标 | 保持优势 + 改正缺点 |

### 1.2 复盘的目的

**三条要点（课件）**

1. 复盘是**行动后的深刻反思和经验总结**
2. 复盘是**提升组织智慧**的手段
3. 复盘是一个**不断学习、总结、反思、提炼和持续提高**的过程

**三角关系图（复盘 → 沉淀 → 创新）**

```
            复盘（Review）
           /            \
     → 沉淀            创新 ←
       (Accumulation)  (Innovation)
```

| 概念 | 空间维度含义 |
|------|--------------|
| **沉淀** | 组织**效率**来源于：沉淀 |
| **创新** | 组织**价值**意味着：创新 |

**易考点**

| 项 | 内容 |
|----|------|
| 复盘定位 | 行动后的**反思 + 经验总结** |
| 作用 | 提升**组织智慧** |
| 过程属性 | 学习→总结→反思→提炼→**持续提高** |
| 三角关系 | 复盘 → 沉淀（效率）/ 创新（价值） |

### 1.4 复盘的类型

**分类矩阵（按 规模 × 对象）**

| 对象 \ 规模 | 个人 | 团队 | 跨部门 |
|--------------|------|------|--------|
| **活动/事件** | 个人复盘 | 团队复盘 | 团队复盘 |
| **项目** | 个人复盘 | 项目复盘 | 项目复盘 |
| **经营/战略** | NA | NA | **战略复盘** |

**四种复盘类型**

| 类型 | 适用规模 | 适用对象 |
|------|----------|----------|
| **个人复盘** | 个人 | 活动/事件、项目 |
| **团队复盘** | 团队、跨部门 | 活动/事件 |
| **项目复盘** | 团队、跨部门 | 项目 |
| **战略复盘** | 跨部门 | 经营/战略 |

**易考点**

- 个人 + 经营/战略 = **NA**（不适用）
- 团队 + 经营/战略 = **NA**
- **战略复盘** 仅在**跨部门 + 经营/战略**场景
- 团队/跨部门 + 活动/事件 → **团队复盘**
- 团队/跨部门 + 项目 → **项目复盘**

### 1.5 正式复盘与非正式复盘

**流程对比**

| 步骤 | 正式复盘（蓝） | 非正式复盘（橙） |
|------|----------------|------------------|
| 1 | **回顾预期目标** | ❌ 跳过 |
| 2 | **回顾过程 / 评估结果** | **评估结果**（不强调回顾过程） |
| 3 | 根因分析 / 关键成功要素 | 根因分析 / 关键成功要素 |
| 4 | 经验教训 / 改进计划 | 经验教训 / 改进计划 |

**相同点**

- 后两步一致：**根因分析/关键成功要素** + **经验教训/改进计划**

**不同点**

| 对比项 | 正式复盘 | 非正式复盘 |
|--------|----------|------------|
| **回顾目标** | ✅ 有 | ❌ 无 |
| **回顾过程** | ✅ 有 | ❌ 无（只评估结果） |
| 流程 | 完整四步 | 精简（省目标、省过程回顾） |

**易考点**

- 非正式复盘**省略**：回顾预期目标、回顾过程
- 两者**共有**：根因分析 + 经验教训/改进计划
- 正式复盘更**完整严谨**；非正式复盘更**轻量**

## 二、复盘有什么价值（五大价值）

> 本章目录：复盘与 3721 原则 → 为什么要复盘（五大价值）→ 复盘的价值。

### 2.1 复盘与 3721 原则

**提升能力的 "7-2-1" 原则**

| 来源 | 占比 | 说明 |
|------|------|------|
| **工作** | **70%** | 经验来自工作实践 |
| **向他人学习** | **20%** | 从其他人身上学习 |
| **正规学习** | **10%** | 课堂/培训等正规学习 |

**图示三场景（课件）**

| 场景 | 占比 | 内容 |
|------|------|------|
| 课堂培训 | 10% | 正规学习（如管理能力培训） |
| 向他人学习 | 20% | 观察、交流、协作 |
| 工作实践 | 70% | 边工作、边学习、边总结、边应用 |

**行动口号（课件）**

> **边工作 边学习 边总结 边应用**

**易考点**

- 7-2-1 = **70% 工作 + 20% 向他人学 + 10% 正规学习**
- **工作实践**是能力提升最主要来源（70%）
- 复盘属于**工作总结**环节，对应 70% 中的"边总结"

### 2.2 为什么要复盘（五大价值）

**四象限（课件图示）**

| 象限 | 内容 |
|------|------|
| 左上（蓝） | **知其然，知其所以然** |
| 右上（深绿） | **不再犯同样的错误** |
| 左下（亮绿） | **总结规律，固化流程** |
| 右下（橙） | **传承经验，提升能力** |

**总结语（红色横幅）**

> **把失败转化为财富，把成功转化为能力**

**五大价值完整列表**

1. 知其然，知其所以然
2. 传承经验，提升能力
3. 不再犯同样的错误
4. 总结规律，固化流程
5. 知识管理中心（经验与教训）

**价值 1 详解：知其然，知其所以然 — 2×2 矩阵**

> 横轴：**绩效**（差 → 好）；纵轴：**学习效果**（差 → 好）

| | 绩效差 | 绩效好 |
|---|--------|--------|
| **学习效果好** | **有意义的失败** | **期望的成功** |
| **学习效果差** | **彻底失败** | **无意义的成功** |

**四象限解读**

| 象限 | 含义 |
|------|------|
| **期望的成功**（绩效好+学习好） | 理想状态：成功且知其所以然，可复制 |
| **有意义的失败**（绩效差+学习好） | 失败但有学习，可为未来成功铺路 |
| **无意义的成功**（绩效好+学习差） | 靠运气成功，不知原因，难复制 |
| **彻底失败**（绩效差+学习差） | 失败且无学习 |

**总结语（红色横幅）**

> 区分"**有意义的失败**"与"**无意义的成功**"

**易考点**

- 复盘目标：向"**期望的成功**"靠拢
- 关键区分：**有意义的失败** vs **无意义的成功**
- 学习效果是纵轴；绩效是横轴（勿混淆）

**价值 2 详解：传承经验，提升能力 — 经验增长曲线**

> 坐标轴：横轴 **时间**，纵轴 **经验**

| 曲线 | 形态 | 含义 |
|------|------|------|
| **期望的状况**（绿色虚线） | **阶梯式上升** | 经验**累积**，每个新阶段从上一阶段结束处继续 |
| **当前的状况**（绿色实线弧） | **周期性归零** | 经验获得但未传递，每次项目/个人都**从零开始** |

**总结语（红色横幅）**

> 如果经验不能有效传递，每个项目，每个人都接近于"**从零开始**"

**易考点**

- 复盘 = 让经验**累积传递**，避免"从零开始"
- 期望：**阶梯式**增长；当前：**周期性归零**
- 与价值1矩阵呼应：有意义的失败/成功都要**沉淀为可传递经验**

**价值 3 详解：不再犯同样的错误 — 循环流程**

```
        纠正错误（蓝）
         ↑        ↓
   分享教训（橙）← 吸取教训（绿）
```

| 步骤 | 颜色 | 含义 |
|------|------|------|
| **纠正错误** | 蓝 | 发现并修正错误 |
| **吸取教训** | 绿 | 从错误中学习 |
| **分享教训** | 橙 | 将教训分享给团队，避免重复 |

**循环关系**：纠正错误 → 吸取教训 → 分享教训 → 纠正错误（闭环）

**总结语（红色横幅）**

> 不宽容失败的组织，将会失去创新和活力，走向僵化。宁肯不干，不可做错

**易考点**

- 三步循环：**纠正 → 吸取 → 分享**（闭环防重犯）
- 文化层面：组织需**宽容失败**以保持创新活力
- "宁肯不干，不可做错" 是需警惕的僵化心态

**价值 4 详解：总结规律，固化流程 — 制度决策流程**

```
是否有制度？
  ├─ 是 → 遵照执行 → 结果是否理想？
  │                       ├─ 是 → 结束
  │                       └─ 否 → 想办法先做起来
  └─ 否 → 想办法先做起来 → 想办法先做起来 → 制定/修订
```

**流程解读**

| 决策/动作 | 含义 |
|-----------|------|
| **是否有制度？** | 判断现有流程/规范是否存在 |
| **遵照执行** | 有制度则按制度执行 |
| **结果是否理想？** | 执行后评估效果 |
| **想办法先做起来** | 无制度或效果不佳时，先实践 |
| **制定/修订** | 实践成熟后，固化/修订制度 |

**易考点**

- 有制度 → **遵照执行** → 理想则**结束**，不理想则**先做起来**
- 无制度 → **先做起来** → 成熟后**制定/修订**
- 核心思想：**先实践后固化**，避免空想制度

**价值 5 详解：知识管理中心（经验与教训）— 案例闭环**

**案例：知识管理启智培训复盘**

| 分析（问题） | 建议（改进） |
|--------------|--------------|
| 专业内容太多且难理解 | 删减不好理解的内容 |
| 对迟到行为没有惩罚 | 增加迟到挑战内容 |
| 20:30 是开始疲劳的时间点 | 精简内容，20:30 开始学员分享 |
| 领导在场，影响其他学员表达 | 副总及以上领导单独成组 |

**实施时间线（建议落地到后续场次）**

```
2班复盘 → 产品研发中心专场复盘 → 3班复盘 → 5班复盘 → ……
```

**闭环逻辑（PDCA 式）**

```
分析（问题）→ 建议（改进）→ 后续场次实施 → 持续优化
```

**易考点**

- 知识管理中心 = **经验与教训**的沉淀与复用
- 案例体现：**分析 → 建议 → 落地到后续场次**的闭环
- 与价值2（传承经验）呼应：经验需**沉淀并传递**到后续项目

### 2.3 复盘的价值

**三个维度的价值（课件）**

| 维度 | 颜色 | 价值 |
|------|------|------|
| **个人** | 蓝 | 从经验中学习，**快速提升能力** |
| **团队** | 红 | 经验**分享与传承** |
| **组织** | 绿 | 知识**萃取与共享**，组织发展与**持续改善** |

**易考点**

- 复盘价值分**三层**：个人 → 团队 → 组织
- 个人：**学习 + 提升能力**
- 团队：**分享 + 传承**
- 组织：**知识萃取 + 共享 + 持续改善**
- 与 1.2（提升组织智慧）、2.2 五大价值形成完整闭环

## 三、复盘成功心法（五心五求）

> 本章目录：复盘成功公式 → 五心五求（待截图补充）。

### 3.1 复盘成功公式

**成功公式（课件图示）**

```
洞察力            说服力              个人影响力        企业竞争力
  │                 │                   │                 │
  ↓                 ↓                   ↓                 ↓
得到复盘结论    复盘得到支持          职场上的成功      市场上的成功
```

**公式拆解**

| 能力（蓝） | 产出（黄） | 层级 |
|-----------|-----------|------|
| **洞察力** | 得到复盘结论 | 输入能力 |
| **说服力** | 复盘得到支持 | 输入能力 |
| **个人影响力** | 职场上的成功 | 输出结果 |
| **企业竞争力** | 市场上的成功 | 输出结果 |

**公式表达**

> **（洞察力 + 说服力）= （个人影响力 + 企业竞争力）**

- 左侧两项是**复盘所需能力**：洞察力得出结论，说服力让结论获得支持
- 右侧两项是**复盘带来的成功**：个人在职场成功，企业在市场成功

**"把式论"（红色横幅）**

| 类型 | 能说？ | 会干？ | 评价 |
|------|-------|--------|------|
| **真把式** | ✅ 能说 | ✅ 会干 | 真本事 |
| **假把式** | ✅ 能说 | ❌ 不会干 | 花架子 |
| **傻把式** | ❌ 不会说 | ✅ 会干 | 干了白干 |

**口诀**

> 能说会干，是**真把式**；能说不会干，是**假把式**；能干不会说，是**傻把式**。

**易考点**

- 成功公式两能力：**洞察力 + 说服力**
- 洞察力 → **得到复盘结论**；说服力 → **复盘得到支持**
- 两能力推导两成功：**个人影响力 → 职场成功**；**企业竞争力 → 市场成功**
- "把式论"三种人：**真把式**（能说会干）/ **假把式**（能说不会干）/ **傻把式**（能干不会说）
- 复盘既要有**洞察**（会干），也要有**说服**（能说），缺一不可——避免"傻把式"

### 3.2 五心（态度：五个"心"）

**五个"心"环形图（课件）**

```
            开放心态（红）
          ╱              ╲
集思广益（橙）        坦诚表达（绿）
          ╲              ╱
   反思自我（青）  ——  实事求是（紫）
```

**五心清单**

| # | 心 | 颜色 | 含义 |
|---|----|------|------|
| 1 | **开放心态** | 红 | 接纳不同观点，不固守己见 |
| 2 | **坦诚表达** | 绿 | 真实、直接地表达想法 |
| 3 | **实事求是** | 紫 | 客观求真，不夸大不掩饰 |
| 4 | **反思自我** | 青 | 从自身找原因，自我审视 |
| 5 | **集思广益** | 橙 | 汇集团队智慧，博采众长 |

**速记口诀**

> 开放、坦诚、求是、反思、集思

**易考点**

- 五心属于**态度**层面（"态度：五个'心'"）
- 五心 = **开放心态 + 坦诚表达 + 实事求是 + 反思自我 + 集思广益**
- 关键区分：
  - **开放心态**：接纳观点（对外）
  - **反思自我**：审视自身（对内）
  - **坦诚表达**：说出来（表达）
  - **实事求是**：说真话（求真）
  - **集思广益**：听大家（汇聚）
- 五心是复盘**态度/心智**基础，与 3.1 成功公式中的"洞察力+说服力"相呼应

### 3.3 五求（目的：五个"求"）

**五求对照表（不是 → 而是）**

| # | ❌ 不是—— | ✅ 而是—— | 求 |
|---|----------|-----------|-----|
| 1 | 自己骗自己，证明自己对 | 重在**实事求是** | **求真** |
| 2 | 流于形式，走过场 | 重在**内容和找原因** | **求实** |
| 3 | 追究责任，开批判会 | 重在**改进和提高** | **求学** |
| 4 | 强调客观，推卸责任 | 重在**反思和自我剖析** | **求内** |
| 5 | 简单下结论，刻舟求剑 | 重在**找到本质和规律** | **求道** |

**五求环形图（课件）**

```
            真（红）
          ╱        ╲
   道（橙）        实（绿）
          ╲        ╱
            学（紫）——内（青）
```

**五求清单**

| # | 求 | 颜色 | 核心要义 |
|---|----|------|---------|
| 1 | **求真** | 红 | 实事求是，不骗自己 |
| 2 | **求实** | 绿 | 重内容、找原因，不走过场 |
| 3 | **求学** | 紫 | 重改进提高，不追究责任 |
| 4 | **求内** | 青 | 重反思自我剖析，不推卸责任 |
| 5 | **求道** | 橙 | 找本质规律，不简单下结论 |

**速记口诀**

> 真、实、学、内、道

**易考点**

- 五求属于**目的**层面（"目的：五个'求'"）
- 五求 = **求真 + 求实 + 求学 + 求内 + 求道**
- "不是/而是"对照是高频考点：
  - 求真：不是"自己骗自己证明自己对"，而是"实事求是"
  - 求实：不是"流于形式走过场"，而是"重内容和找原因"
  - 求学：不是"追究责任开批判会"，而是"重改进和提高"
  - 求内：不是"强调客观推卸责任"，而是"重反思和自我剖析"
  - 求道：不是"简单下结论刻舟求剑"，而是"找本质和规律"
- 与 3.2 五心呼应：**五心是态度，五求是目的**，共同构成复盘成功心法
