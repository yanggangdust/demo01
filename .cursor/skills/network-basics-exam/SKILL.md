## 一、网络模型与协议介绍

### OSI 七层 vs TCP/IP 四/五层

| OSI 七层 | TCP/IP（四/五层） | 典型协议 |
|---|---|---|
| 应用层 | 应用层 | HTTP、FTP、TFTP、DNS、DHCP、Telnet |
| 表示层 | （并入应用层） | — |
| 会话层 | （并入应用层） | — |
| 传输层 | 传输层 | TCP、UDP |
| 网络层 | 网际层 | IP、ICMP、ARP、RARP |
| 数据链路层 | 网络接口层（链路层） | Ethernet、Wi-Fi |
| 物理层 | （网络接口层） | 物理介质 |

记忆：OSI 七层 = 应表会传网数物；TCP/IP 常按四层（应用/传输/网际/网络接口）或五层（拆出链路+物理）讲。

## 二、网络转发原理

### 1. 二层转发（同网段）
- 基于 **MAC 地址**，在本地网段内转发。
- 交换机查 **MAC 地址表**（CAM 表）决定出接口。
- 同网段通信不跨路由。

### 2. 三层转发（跨网段）
- 基于 **IP 地址**，由路由器在不同网段间转发。
- 每跳 **源/目的 MAC 会变**（逐跳重封装），**源/目的 IP 通常不变**（端到端）。
- 查 **路由表**选下一跳。

### 3. 不同点对比

| | 二层转发 | 三层转发 |
|--|----------|----------|
| 依据 | MAC 表 | 路由表（IP） |
| 设备 | 交换机 | 路由器 / 三层交换机 |
| 范围 | 同网段 | 跨网段 |
| 速度 | 快（硬件/ASIC） | 相对慢（查路由） |
| 地址变化 | MAC 不变（同段） | 每跳 MAC 变，IP 不变 |

## 三、常用网络工具及指令

### 1. 连通性 / 端口 / 路由命令

| 用途 | Windows | Linux/Mac |
|---|---|---|
| 查端口是否开启 | `telnet [IP] [端口]` | `telnet` / `nc`（netcat） |
| 检测连通性 | `ping` | `ping` |
| 追踪路径 | `tracert` | `traceroute` |
| 查看本机地址 | `ipconfig` | `ifconfig` / `ip addr` |
| 查看路由表 | `route print` | `netstat -rn` / `route -n` |
| 添加静态路由 | `route add ...` | `route add ...` / `ip route add` |
| 删除/清空静态路由 | `route delete *` | `route delete` / `ip route del` |

要点：
- `telnet [IP] [端口]`：测远端服务是否监听该端口。
- `ping`：测两台主机基本连通（ICMP）。
- `tracert/traceroute`：看包走的路径、在哪一跳丢。

### 2. 抓包工具

| 工具 | 形态 | 特点 |
|---|---|---|
| **Wireshark** | GUI | 三栏（包列表 / 包详情 / 十六进制），适合详细分析 |
| **tcpdump** | CLI | 轻量，适合服务器上抓包 |

## 四、网络设备及其使用场景

### 1. 路由器
- 功能：数据包转发、路由表更新、路由选择算法、网络安全功能。
- 场景：企业网络、数据中心互联、远程办公支持、家庭网络。

### 2. 交换机
- 功能：
  - 数据帧接收与解析
  - **MAC 地址表学习**（源 MAC + 入端口）
  - 数据帧转发
  - **泛洪与过滤**
  - **生成树协议 STP**（防二层环路）
- 转发逻辑：
  - **泛洪 Flooding**：广播 / 组播 / 未知单播
  - **转发 Forwarding**：已知单播
  - **丢弃 Discarding**
- 场景：企业内部网络、数据中心、云计算环境、无线局域网。

### 3. 防火墙
- 功能：
  - **包过滤技术**：基于 IP/端口头部静态过滤
  - **状态检测技术**：跟踪活动连接状态
  - **代理服务技术**：客户端与服务器间的中介
  - **深度包检测 DPI**：检查数据负载，不只是头部
- 场景：企业内部网络安全、远程访问安全、电子商务安全、数据中心安全。
- 详见 `firewall-exam` skill。

### 4. 汇聚分流
- 功能：数据包接收与解析、数据汇聚、数据分流、数据过滤安全。

### 5. 其他网络设备
- 负载均衡 / AC / AP 等，按教材补充。

## 五、网络维护常见词汇

### 1. 二层概念
- **VLAN**：逻辑划分物理网络，提升安全、减少广播风暴。
- **Access / Trunk 口**：
  - Access：接终端（PC），带一个 VLAN。
  - Trunk：连交换机，承载多 VLAN 流量。
- **STP（生成树协议）**：阻塞冗余路径，防二层环路。
- **二层交换机**：基于 MAC 在同局域网内转发。

### 2. 三层概念
- **路由器**：连接不同网络，基于 IP 转发。
- **三层交换机**：带路由能力的交换机，常用于高速 VLAN 间路由。
- **路由协议**：
  - 静态路由：手工配置。
  - 动态路由：**OSPF**、**BGP** 等。

### 3. 无线网络 WLAN
- **SSID**：网络名。
- **AP**：接入点。
- **AC**：无线控制器，管理多个 AP。

### 4. 网络安全
- **防火墙**：包过滤 / 状态检测 / 代理 / DPI（详见 `firewall-exam`）。
- **VPN**：在公网上建加密隧道。
- **WAF**：Web 应用防火墙，防 SQL 注入等。
- **IPS/IDS**：入侵防御 / 检测系统。
- **NGFW（下一代防火墙）**：传统防火墙 + DPI + IPS + 应用级控制。

## 六、网络安全与综合管理

### 1. 常规维护与状态巡检
- 网管系统仪表盘：CPU 使用率、内存利用率、活跃会话数等实时指标。

### 2. 安全工作流（数据采集与解析）
流程：**数据采集与解析 → 异常诊断 → 策略变更 → 数据持久化安全**（监控-诊断-改策略-保完整性的循环）。

### 3. 网络常见故障
- **网络连接异常**：通用连通性排查。
- **二层广播风暴及环路**：
  - 现象：环路导致广播风暴，交换机 CPU 飙高、网络瘫痪。
  - 排查：看日志/诊断输出，定位环路口；用 STP 防环路。
  - 表现：某端口出现环路告警，交换机 CPU 占用高。

## 七、园区网

### 1. 架构（三层）

| 层 | 作用 | 关注点 |
|---|---|---|
| **核心层** | 高速骨干 | 快速包交换、高可用 |
| **汇聚层** | 接入与核心间的桥 | 策略、路由、流量过滤 |
| **接入层** | 终端入口 | 端口安全、VLAN 打标 |

### 2. 交换机制
- **MAC 地址表**：交换机"学习"哪个 MAC 在哪个口。
- **转发逻辑**：泛洪 / 转发 / 丢弃（见第四节）。
- **STP**：防二层环路。

### 3. 典型功能分区
- **内网终端**：用户办公区。
- **数据中心**：服务器、存储。
- **出口 / DMZ**：内网与公网边界，放防火墙和对外服务器。
- **WLAN**：AP + AC 管理无线。
