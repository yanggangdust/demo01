## 一、移动云产品体系

> 本章目录（Part 1）：体系概述 → 基础产品 → 特色产品 → 开放云市场产品。

### 1.1 体系概述

**核心概述（课件）**

> 移动云自有产品目前已上线 **230 余款**，覆盖**基础产品、特色产品**等**全栈产品体系**，产品规模已进入**第一阵营**。

**全栈架构（三层 + 两侧）**

```
        解决方案（10 行业）
              │
    SaaS ─────┼───── 专业服务
    PaaS      │
    IaaS      │
              │
```

#### SaaS 层

| 类别 | 产品 |
|------|------|
| **自有 SaaS** | 桌面云、中移商情、云空间、数据侠 APP、中移党建云、中移舆情、灯塔舆情 |
| **引入 SaaS** | 小步外勤、金蝶会计、老板签批 |

#### PaaS 层

| 类别 | 产品 |
|------|------|
| **数据库** | MySQL PXC、Redis |
| **大数据** | 大数据处理、数据集成、数据可视化 |
| **中间件** | RocketMQ、MQTT、kafka |
| **人工智能** | AI 训练平台、AI 能力开放 |
| **开发者服务** | 云 API、微服务平台、代码托管 |
| **视频服务** | 视频点播、视频直播、媒体转码 |
| **企业应用** | 云桌面、备案 |

#### IaaS 层

| 类别 | 产品 |
|------|------|
| **弹性计算** | 云主机、GPU 云主机、专属云、物理机、弹性伸缩、镜像服务、容器服务、容器镜像服务 |
| **弹性存储** | 对象存储、云硬盘、文件存储、云硬盘备份、云主机备份、存储网关、云空间 |
| **云网络** | VPC、负载均衡、弹性公网 IP、共享带宽、共享流量、NAT 网关、对等连接、IpsecVPN、SSL VPN、IPv6 转换、CDN、云宽带、云专线、云互联 |
| **云安全** | 抗 DDoS、WAF、漏洞扫描、云主机安全、云防火墙、云堡垒机、抗 D 高防、WEB 全栈防护 |
| **管理与监控** | 云监控、云审计、统一身份认证（IAM）、APM、消息通知服务、云日志 |

#### 解决方案（10 行业）

通用 / 工业与能源 / 交通 / 教育 / 金融 / 医疗 / 互联网 / 媒体 / 政府 / 农商

#### 专业服务

**运维服务：** 云上护航、重大活动保障、健康检查、企业服务报告、第三方软件支持、架构咨询、上云支持、数据库优化、中间件优化

**安全服务：** 安全管家、安全评估、渗透测试、等保咨询、应急响应、漏洞扫描、安全培训

**IaaS 五大类速记**

> 计算 / 存储 / 网络 / 安全 / 管监

**PaaS 七大类速记**

> 数据库 / 大数据 / 中间件 / AI / 开发者 / 视频 / 企业应用

**易考点**

- 自有产品 **230 余款**；**全栈**体系；规模**第一阵营**
- 架构 = **SaaS + PaaS + IaaS** + **解决方案** + **专业服务**
- SaaS 分**自有**（7 个）和**引入**（3 个）
- IaaS 五大类 = **弹性计算 / 弹性存储 / 云网络 / 云安全 / 管理与监控**
- PaaS 含：**数据库、大数据、中间件、AI、开发者、视频、企业应用**
- 解决方案 **10 行业**：通用/工能/交通/教育/金融/医疗/互联网/媒体/政府/农商
- 专业服务分**运维服务**和**安全服务**两大类
- 与《移动云整体介绍》3.2 呼应：产品规模**第一阵营**
- 易错点：**230 余款**是自有产品总数；IaaS 最底层；**引入 SaaS** 非自有（小步外勤/金蝶/老板签批）

**与 1.1 体系概述关系**

|---------|-------------|
| IaaS 五大类 | **弹性计算 + 云存储 + 云网络 + 云安全**（IaaS 核心） |
| PaaS 部分 | **数据库 + 中间件**（PaaS 基础） |

**易考点**

- 基础产品六大类 = **弹性计算 + 云存储 + 云网络 + 云安全 + 数据库 + 中间件**
- 中间件四大消息队列 = **Kafka / MQTT / RocketMQ / RabbitMQ**
- 云存储特色：**蓝光存储、云归档、CBR 云备份**
- 云安全最全（12 项）：含**下一代防火墙、态势感知、SSL 证书**等
- 弹性计算含：**云电脑、裸金属、专属宿主机**（非仅云主机）
- 云网络：**云组网/云互联**（与整体介绍 2.3 呼应）
- 易错点：**数据库/中间件**属基础产品（PaaS 层）；**云备份 CBR** 在云存储（非计算）；四大 MQ 勿漏 **RabbitMQ**

### 1.3 特色产品

**概述：** 移动云特色产品 = **"四融"产品**

| # | 四融 | 名称 |

**四融与《移动云整体介绍》1.2 呼应**

| 整体介绍 1.2 四融 | 产品能力培训 1.3 四融 |
|-----------------|---------------------|
| 云智融合 | **云智融合** |

- 特色产品 = **四融产品**：**云网一体 / 云数融通 / 云智融合 / 云边协同**
- **云网一体**：接入（云专线/云端口/5G云梯）+ 云间（云互联/云组网）
- **云数融通**：数据应用（中移舆情/商情/梧桐系列）+ 大数据（MapReduce/可视化/治理）
- **云智融合**：AI 能力 7 项 + 平台 3 项（**智算平台、大模型服务平台**）
- **云边协同**：边缘应用 4 项 + 平台 4 项 + 基础设施（**EIC / EIS**）
- 边缘基础设施：**EIC**（边缘智能云）、**EIS**（边缘智能小站）
- 易错点：**云网一体**（非"云网融合"，本课产品名）；**5G 云梯**在接入网络；**大模型服务平台**在云智融合

### 1.4 开放云市场产品

**课件标题：** 移动云云市场频道

移动云云市场频道

政务 / 医卫 / 教育 / 金融 / 交通 / 农商 / 工业能源 / 互联网 / …

**六大类速记**

> 企应 / 安全 / 专服 / 行应 / 建站 / AI

|------|------|

## 二、移动云产品推广

> 本章目录（Part 2）：云主机 → 云硬盘 → 弹性公网 IP → 对象存储 → 云数据库 MySQL → 云专线 → 边缘小站 → 智算平台 → 云安全中心 → 云空间 → 云电脑。

### 2.1 云主机

> 本节结构：产品功能（功能/类型/优势）→ 主要场景 → 经典案例。

#### 2.1.1 产品功能

**产品定义（课件）**

> 云主机是一种**按需获取**的云端服务器，通过**虚拟化技术**整合 IT 资源，提供**高可靠、弹性扩展、按需使用**的计算资源服务。

用户可按需选择 **CPU、内存、操作系统、存储、网络**，满足通用 Web 应用、日志分析、机器学习、科学计算等个性化业务需求。

**云主机基础配套产品（6 项）**

| # | 配套产品 |
|---|---------|
| 1 | **镜像服务** |
| 2 | **云硬盘** |
| 3 | **弹性公网 IP** |
| 4 | **虚拟私有云（VPC）** |
| 5 | **云安全中心** |
| 6 | **云主机备份** |

**规格类型（课件表格）**

| 类型 | 规格描述 |
|------|---------|
| **通用入门** | **2.3GHz Intel Xeon Gold**；CPU:内存 = **1:1 / 1:2 / 1:4**；CPU 超分 |
| **通用型** | **X86**（Intel/AMD/海光）+ **ARM**（鲲鹏）；CPU 超分 |
| **通用网络优化** | **2.4/2.5/3.0GHz Intel Xeon Gold**；CPU:内存 = **1:2 / 1:4**；高性能网络 |
| **内存优化型** | **2.3/2.5/3.0GHz Intel Xeon Gold**；CPU:内存 = **1:8**；最大内存 **640G** |
| **内存网络优化** | **2.5/3.0GHz Intel Xeon Gold**；CPU:内存 = **1:8**；最大 **640G**；**独享 CPU**（无争抢） |
| **计算型** | **3.0GHz Intel Xeon Gold**；CPU:内存 = **1:2 / 1:4**；**独享 CPU** |
| **计算网络优化** | **3.0GHz Intel Xeon Gold**；CPU:内存 = **1:4**；**独享 CPU**；内网带宽最高 **30Gbps** |
| **大数据型** | **2.5GHz Intel Xeon Gold**；CPU:内存 = **1:4**；**独享 CPU**；多块 **SATA HDD 本地盘**，高 I/O、低时延 |

**其他类型（课件备注）**

超大内存型、超高频型、存储增强型、通用网络增强型、通用计算增强型、**GPU 云主机**等

**核心优势（三大项）**

##### 1. 弹性易用

| 要点 | 内容 |
|------|------|
| 计费 | 多种计费模式，适配不同业务场景 |
| **垂直伸缩** | 按需分钟级调整 CPU/内存；带宽/系统盘/数据盘**在线不停机**升级 |
| **水平伸缩** | 结合**弹性伸缩（AS）**，按流量峰谷自动扩缩容 |

##### 2. 稳定可靠

| 要点 | 内容 |
|------|------|
| 认证 | 国际权威 + **可信云**认证 |
| **服务可用性** | **99.975%** |
| **数据可靠性** | **99.999999999%**（**11 个 9**），备份多副本 |
| 安全 | 满足**等保三级**，灵活安全组合 |

##### 3. 按需购买

| 要点 | 内容 |
|------|------|
| 架构 | 支持 **X86 + ARM** 两大计算架构 |
| 类型 | 通用型、内存型、计算型、大数据型等多种规格 |

**易考点（2.1.1）**

- 定义关键词：**按需、虚拟化、高可靠、弹性扩展**
- 配套 **6 项**：镜像/云硬盘/EIP/VPC/云安全中心/云主机备份
- **独享 CPU**（无争抢）：内存网络优化、计算型、计算网络优化、大数据型
- **CPU:内存 1:8 + 640G**：内存优化型、内存网络优化
- **内网 30Gbps**：计算网络优化
- **ARM 鲲鹏**：通用型
- 可用性 **99.975%**；数据可靠性 **11 个 9**
- 垂直伸缩 = CPU/内存/磁盘**在线升级**；水平伸缩 = **弹性伸缩 AS**
- 易错点：**通用入门**有 **1:1** 配比（其他型少见）；大数据型用**本地 SATA HDD**（非云盘）

#### 2.1.2 主要场景

**概述（课件）**

移动云云主机适用于**教育、互联网、农商、政府、医疗、交通、工业能源、金融**等多个行业；根据不同应用场景，为千行百业提供**按需购买、弹性易用、稳定可靠**的各层级计算服务。

**适用行业速记（8 个）**

> 教育 / 互联网 / 农商 / 政府 / 医疗 / 交通 / 工业能源 / 金融

### 2.2 云硬盘

> 本节结构：产品功能（功能/类型/特点）→ 主要场景 → 经典案例。

#### 2.2.1 产品功能

**产品定义（课件）**

> **云硬盘**：为云主机提供的**高可靠、高并发、低延时、大容量****块存储**产品。

**用途与实现**

| 要素 | 内容 |
|------|------|
| **用途** | 为**云主机、裸金属**提供**系统盘**和**数据盘**；可格式化、创建文件系统，如传统硬盘 |
| **底层** | 基于**分布式存储系统** |
| **可靠性** | **多副本强一致性**，保障数据可靠 |

**云硬盘类型（7 种，课件）**

| 类型 | 特点 | 介质/技术 | 性能 |
|------|------|----------|------|
| **容量型** | 高可靠、大容量、**低成本** | **SATA** | — |
| **性能型** | — | — | **（售罄）** |
| **性能优化型** | 高可靠、高安全、**高性能** | **SSD + HDD 混合**架构 | — |
| **高性能型** | **超高性能** | **全 SSD** | — |
| **极速型 L1** | 极高性能、超低时延 | **25GE 网络 + RDMA** | 单盘最大 **5 万 IOPS** |
| **极速型 L2** | 极高性能、超低时延 | **25GE 网络 + RDMA** | 单盘最大 **10 万 IOPS** |
| **极速型 L3** | 极致性能 | **25GE + RDMA** | 单盘最大 **100 万 IOPS**；时延 **百微秒级** |

**类型选型速记（性能由低到高）**

```
容量型(SATA) → 性能优化型(SSD+HDD) → 高性能型(全SSD) → 极速L1(5万) → L2(10万) → L3(100万/百微秒)
```

#### 性能指标（相互独立又相互关联）

| 指标 | 英文 | 定义 | 要点 |
|------|------|------|------|
| **IOPS** | Input/Output Operations Per Second | 单位时间最大 **IO 频度**（每秒读写次数） | **存储系统性能最主要指标** |
| **带宽** | Throughput | 单位时间最大 **IO 流量**（大 IO 块+大带宽获最大流量） | 也称**吞吐量** |
| **时延** | Latency | 单个 IO 请求**开始到结束**的时间 | **≤20ms** 应用基本正常；核心交易系统建议 **≤10ms** 或更快 |
| **容量** | Capacity | 云硬盘最大可存储数据量 | IOPS/带宽可与容量**线性相关**——**容量越大，读写性能越好** |

**选型指导（课件红色总结）**

| 业务类型 | 重点关注 |
|---------|---------|
| **频繁随机读写** | **IOPS + 时延** |
| **大量顺序文件访问**（数据仓库、流媒体等） | **带宽** |

**易考点（2.2.1）**

- 云硬盘 = **块存储**；四特性：**高可靠、高并发、低延时、大容量**
- 用途：**系统盘 + 数据盘**（云主机/裸金属）
- 底层：**分布式存储** + **多副本强一致性**
- **容量型** = **SATA**，低成本大容量
- **性能优化型** = **SSD+HDD 混合**
- **高性能型** = **全 SSD**
- **极速型** = **25GE + RDMA**；L1/L2/L3 IOPS = **5万/10万/100万**
- **L3** 时延 = **百微秒级**
- **性能型**已**售罄**
- **四大性能指标**：IOPS / 带宽 / 时延 / 容量（独立又关联）
- **IOPS** = 最主要指标；随机读写看 **IOPS+时延**；顺序大文件看 **带宽**
- 时延经验值：**20ms** 正常、**10ms** 核心交易系统
- 容量与 IOPS/带宽**线性相关**（越大性能越好）
- 易错点：极速型三档看 **IOPS 数量级**；L3 是 **100 万 IOPS**（非 10 万）；**带宽≠IOPS**
